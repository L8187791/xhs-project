**闸门实现**：`compliance_gate.py` **v3.8 — 只查 P0**；`P0 > 0` 就不发稿。

### 🔑 唯一豁免机制（很重要，别误伤自己）

`has_verifiable_evidence()` + `exempt_urgency`：

| 写法                                | 判定                          |
| --------------------------------- | --------------------------- |
| 「今晚 24:00 截止」                     | ❌ 单独出现 → P0                 |
| 「我 10-10 15:20 核到招行官网写的是今晚 24:00」 | ✅ 与**核验时间 + 具体日期**同时出现 → 放行 |

> **只对「紧迫类」豁免**。诱饵引流 / 商品引导 / 焦虑贬损 / 绝对化用语 / 数字待复核 **一律不豁免**。  
> 常驻回归套件 `_regression_gate.py` **实跑 39/39 全绿**。
