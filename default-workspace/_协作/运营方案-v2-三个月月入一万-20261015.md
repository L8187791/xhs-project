### 2.2 人设三支柱

| 支柱 | 内容 | 与竞品的差异 |
|---|---|---|
| **① 身份真实** | 「普通打工人」，不包装大厂学姐/HR/名师 | 竞品用「25届理工科大厂学姐」；**我们主动放弃这部分说服力，换来零可证伪的虚假陈述** |

| **③ 立场** | 站求职者一侧，反「信息差收割」 | 「我也是被坑过的人」是天然共情句 |

### 2.3 🔴 简介必改（只有 L 能改）

- **现文**：…整理 **2027 届**秋招网申截止时间表、简历模板，**截止日期逐家核过官网**。
- **两处问题**：①「2027 届」违守则 55；②「逐家核过官网」与实况不符（C 级占比 33%）→ **虚假陈述敞口**（同一句商品页已删、简介仍留）。

  > 普通打工人，找工作时被信息差坑过。整理 **2026 秋招**网申截止时间表，每条都标核验来源与日期，**你可以自己再核一遍**。

### 2.4 禁止的人设动作

- ❌ 编造身份 / 学历 / 实习 / offer / 上岸经历
- ❌ 「学姐 / 学长 / HR / 面试官」等**无法验证的关系标签**

|---|---|

| 当前客单 **19.9** | 客单提到 **49.9 / 99** 后，期待落差 → 退款率**大概率上升** |
| 虚拟商品行业常见退款率 | **5% – 15%** |
| 店铺升级后 | 有了评价体系与官方纠纷通道 → **退款更"容易"发起** |

**→ 处置**：事实口径按 0.98 结算，**规划口径按 0.931**。
**触发规则**：连续 30 天实测退款率 **<3%** → 规划口径上调到 0.95；若 **>8%** → 立刻回查商品详情页 5 项是否写全。

### 6.1·补·三 2% 扣点买到了什么

| 项 | 值 |
|---|---|
| 扣点成本 | 10,741 × 2% = **215 元/月** |
| 换来的能力 | **店铺访客 / 商品曝光 / 商品点击 / 支付转化 四段数据可见** |
| 换来的优化空间 | 把观看→成交从 **0.02% 修到 0.25%（12.5 倍）** |

> **结论：215 元/月买一个可优化的漏斗——本项目最便宜的一笔投入。**
> 个人售卖省下 2%，但代价是**永远看不见漏斗中段**，等于放弃优化能力。

## 七 · 内容策略：把爆款从"偶然"变成"日产能"

### 7.1 现状的真实问题

| 事实 | 数字 |
|---|---|
| 单篇最高观看 | **3,102**（10-08 爆款） |
| 其余篇观看中位 | **~40** |
| 差距 | **70–220 倍** |
| 需要达到 | **单篇平均 880 观看**（3 篇/天 → 2,640/天） |

**→ 核心命题不是"多发"，是"把爆款那个组合拆出来复用"。**

### 7.2 🔴 爆款公式（我方 A 级实测，最高优先级）

> ### **具体数字 + 今天/截止 + 可核验**

| 对照 | 爆款 | 其余 6 篇 |
|---|---|---|
| 标题 | 「**4 家**银行」 | 「三种表现」← 也有数字，但**无时效** |
| 时间锚点 | 「**今天**截止」 | 「更新了，就在今天 24 点」← **含糊** |
| 可核验 | 「**附官网核验时间**」 | 无 |
| 内容性质 | **读者今天就要用的信息** | 方法论 / 自我宣传 |

**每一篇选题前必须回答：这条能用哪个「X 家 / 今天 / 本周」锚点？答不出就换题。**

### 7.3 四层内容重构（旧 A/B/C 三层 → 四层）

| 层 | 栏目 | 选题类型 | 时段 | 作用 |
|---|---|---|---|---|
| **A** | 截止节点 | **今日截止 / 未来 7 天 / 本周汇总 / 月度总表**（4 种锚点轮换，解决"某天无料"断料问题） | 09:00 | **转化器** |
| **B** | 机会型 | 双非友好 / 免笔试 / 大厂幼年体 / 中小厂 / 外企 | 12:30 | 🔴 **流量放大器**（红狐天花板万赞级） |
| **C** | 人群型 | 往届可投 / 第一人称经历型 | 20:30 | **第二客群 + 收藏入口** |
| **D** | **季节型**（11/15 起启用） | 秋招补录 / 春招提前批 / 寒假实习 / 社招转校招 | 按周插播 | 🔴 **穿越 12 月断层** |

**配比**：10/15–11/30 = **A + B + C**；12/1 起 = **A + D + C**（B 让位给 D）

### 7.4 选题定题：红狐评分法（六维 100 分）

| 维度 | 权重 | 分档 |
|---|---|---|
| **评论率代理**（样本评/赞中位） | **35** | ≥0.30→35 ｜ 0.20–0.30→28 ｜ 0.15–0.20→21 ｜ 0.10–0.15→14 ｜ <0.10→7 |
| 爆款天花板（赞中位） | 20 | ≥5000→20 ｜ 3000–5000→16 ｜ 1000–3000→12 ｜ 500–1000→8 ｜ <500→4 |
| 高互动占比（评/赞≥0.3 篇数占比） | 15 | ≥30%→15 ｜ 20–30%→11 ｜ 10–20%→7 ｜ <10%→3 |
| 头部爆款（样本内最高赞） | 15 | ≥2万→15 ｜ 1万–2万→11 ｜ 5000–1万→7 ｜ <5000→3 |
| 可核验性 | 10 | 表内可核→10 ｜ 部分可核→5 ｜ 完全表外→**0 且标 P0 敞口** |
| 母版间隔 | 5 | 不撞→5 ｜ 相邻不撞→2 ｜ 撞车→**0 淘汰** |

**一票否决**：V1 B/C/D 同方向 <3 天（A 层豁免但须换讲法 ≥2 项）｜V2 需精确数字而表内不可核｜V3 样本 n<5｜V4 命中 P0

🔴 **分数之上一条总规则：我方后台 A 级实测 > 红狐 B 级评分。** 红狐只用于**没有我方数据的空白处**。

### 7.5 写法类型优先级（红狐 114 篇实证，B 级）

**清单/汇总型 0.250 > 第一人称经历型 0.191 > 单家深挖 0.108 > 反直觉结论型 0.075（最差，0% 进高互动区）**

### 7.6 🔴 产能设计：**不追篇数，追"单篇观看中位"**

- 封顶 **3 篇/天**（单人产能天花板，超过则质量崩）
- 复盘唯一指标 = **单篇观看中位**（不是总量，总量会被爆款掩盖）
- **熔断**：连续 3 天单篇中位 < 200 → 停止出稿 1 天，回查选题
- 拒绝"密度换量"：实测 **≥5 篇/天组平均观看 42.6 vs 全站中位 176.2 = 4.1 倍差距**

| 卡机制 | **保留**，但只作 **W → L 的交付载具** 与**策略留痕** |
| 卡号 | `WB` 继续递增；`DB` 分区归档不再新增 |
| 无人值守 | 取消 30 分钟轮询；改为「W 自主出稿 → 进桌面包 → 等 L 拍板」 |

### 11.6 出稿必经顺序（不可颠倒）

```
定题（红狐评分，稿头写 `## 定题`）
 → 二创六步（含 Humanizer）
 → 同质化五查（`_sim_check.py`）
 → 合规闸门（`compliance_gate.py`，要求 P0=0）
 → 字段一致性体检（稿 = 主表）
 → 定稿 → 落档（发布包 + 卡索引 + 桌面包）
```
🔴 **改动即失效**：定稿后改标题/正文/首评/标签/**图内文案**任一处 → 重跑 Humanizer + 五查 + 重渲。
🔴 **发布不经 AI 手**（L 是唯一平台操作者）。
