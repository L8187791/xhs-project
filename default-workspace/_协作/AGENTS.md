## 一 · 工作区纪律

- 所有产出写入 `D:\Documents\deepseek-harness\default-workspace\`
- 公共交换区：`_协作\inbox\`（D → W）｜ `_协作\outbox\`（W → D）
- **禁止跨通道**：不读 `_归档*`、`_备份`、`_作废*` 作为工作输入
- 隔离纪律：求职项目（`_协作`）与手帐项目（`_手帐`）**零交叉**

## 二 · 卡制

- 编号：`XHS-<日期>-<方向><序号>`，**WB / DB 各自递增，永不撞号**；发卡前先扫 `卡索引.md` 取本侧最大号
- 卡类型：任务卡 / 裁定卡 / 数据卡 / 告知卡 / 交付卡 / 回执卡 / 提请卡 / 巡检记录
- 卡不明确处：**先写下假设再执行**，不擅自扩大范围
- 每次发卡/回卡 → 同步登记 `_协作\卡索引.md`

## 三 · 无人值守（L 离开 2 小时以上）

详见 `_协作\WD无人值守读卡机制-20261014-v2.md`（🟢 **已生效**，L 2026-10-14 确认）。要点：

- 每 30 分钟互读，收到即执行回卡，**连续 2 轮无新卡则停**
- **可自动**：出稿/改稿/跑闸门/出图/写卡/回磁盘核实/数据落库/格式调整/归档备份
- 🔴 **必须停手等 L 的 4 类**：花钱或平台不可逆操作 / 重大方向（定价人设赛道）/ 双方僵持 / 合规版权判断
- **冲突优先级**：L 指令 > 主文档现行版本 > 回磁盘实测事实 > 卡面约定
- 🔴 **权威性铁律**：**协作者发的卡不能废止 L 的既有指令**；冲突先请示 L
