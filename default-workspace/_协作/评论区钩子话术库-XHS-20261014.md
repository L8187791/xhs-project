## 一 · 实证结论：什么样的笔记才会有评论

### 1.1 高评论篇的结构命中率（评论/点赞 > 0.3，n=16）

| 结构 | 命中 | 占比 |
|---|---|---|
| **人群点名**（双非 / 985 / 27届 / 往届生 / 水硕 / 博士） | 7/16 | **44% ← 最高** |
| 疑问句（吗 / ？） | 3/16 | 19% |
| 召唤评论 / 两难 / 情绪词 / 反直觉 / 求助式 | 0/16 | 0% |

> ⚠️ n=16 样本偏小，0% 项**不能解读为"无效"**，只能说明在本次高评论样本里没出现。

### 1.2 关键样本：留缺口 = 评论炸弹

| 标题 | 赞 | **评论** | 说明 |
|---|---|---|---|
| **3类没人知道的高薪公司，双非大专也能进！** | 30000 | **10000** | 说「3 类」**不给名字** → 评论区全在问具体公司 |
| 好多秋招要截止了🥲 | 5000 | **1489** | 时效紧迫 + 哭脸 emoji |
| 985本科和双非硕士选哪个？😭第一学历重要吗 | 956 | **549** | 两难选择 + 身份焦虑 |
| 希望校招也能看到此番景象🥺 | 3639 | **4138** | 愿望式 + 🥺（评论 > 点赞） |
| 秋招急了，免笔试！ | 489 | **174** | 时效 + 利益，短句 |
| 港大是真饿了吗😓一堆双非 | 2698 | **1599** | 反常现象 + 人群点名 |

> 🔴 **这条直接验证我们的「不说全」纪律**：最高评论的那篇（1 万条）恰恰是**说了数量、没说名字**。
> 「不说全」不只是为了卖货，它本身就是评论率发动机。

### 1.3 反例：给结论 / 给方法 → 高赞高藏但零评论

| 标题 | 赞 | 评论 | 评论/点赞 |
|---|---|---|---|
| 双非本科人请进‼️3步轻松捡漏神仙offer～ | 4496 | **6** | 0.001 |
| 大学生自我提升｜双非逆袭｜私藏公开课推荐 | 5000 | **12** | 0.002 |
| 我发现，可以按相亲的思路准备秋招 | 4218 | **18** | 0.004 |
| 其实外企还是偏爱往届生 | 1451 | **13** | 0.009 |
| 要的就是往届生 | 1414 | **11** | 0.008 |

> **规律（可证伪）**：把答案给全 = 用户拿走就走，**零评论**。
> 留一个缺口 + 点名人群 = 用户必须开口问。

## 三 · 按层级落地（可直接复制）

### 3.1 正文结尾 CTA（必须是问题，禁总结陈词）

| 层级 | 结尾 CTA | 备注 |
|---|---|---|
| **A 层时效稿** | 「你今天投了哪家？评论区告诉我，我看看还有没有漏的。」 | 封闭式 + 低门槛 |

## 四 · 禁区（P0 / P1，碰了直接退回）
