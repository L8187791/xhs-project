## 〇 · 一句话总览

**出稿流程**：定题 → 二创六步（含 Humanizer）→ 同质化五查 → 标题二创 5 查 → 闸门 P0 → 字段一致性体检 → 出图（strict）→ 三层自检 → 定稿落档 → 交付桌面包

**五条主轴纪律**：① 顺序铁律（二创→定稿→落档）② 改动即失效 ③ P0 零容忍 ④ 不说全（留白）⑤ 发布不经 AI 手

## 一 · 出稿全链（不可颠倒）

> 出处：C02 §二 Z2-1（全链定义）＋二创规则 v2.2 §〇（顺序铁律）

| 步 | 动作 | 判据 / 工具 | 产物 / 留痕 |
|---|---|---|---|
| **1** | **定题** | 红狐六维评分（≥3 候选→取最高分）＋一票否决 V1–V4 | 稿头 `## 定题` 一行 |
| **2** | **二创六步** | ①识别核心论点不改关键信息 ②模仿真人文风 ③同义替换+适度扩展 ④按段落重述+第一人称见解 ⑤**跑 Humanizer** ⑥留白 | 稿头 `## 二创` 一行 |
| **3** | **同质化五查** | `_sim_check.py --new … --recent 3`（R1–R5） | 稿头 `## 五查` 一行 |
| **4** | **标题二创 5 查** | T1–T5（Jaccard/违禁词/≤20字/人群词前置/换结构） | `…｜标题二创=T1~T5 过` |
| **5** | **母版比对**（人工） | 列最近 3 天产物清单逐一比对 | 二创行内写明母版 |
| **6** | **P0 闸门** | `compliance_gate.py <显式路径>` | **P0=0**（水准线 P1=0） |
| **7** | **字段一致性体检** | `字段一致性体检.py`（稿 = 主表） | 通过 |
| **8** | **出图** | `ganhuo_lib.render(strict=True)` | 图序 `big→list→big` |
| **9** | **三层自检 + 落档** | 稿头状态行 `**状态**：定稿` | 发布包 + 卡索引 + 桌面手机端包 |
| **10** | **交付** | 桌面包（文案.txt + 图1/2/3 + 00-先看这个.txt） | 回磁盘取证 |

🔴 **顺序铁律**（L 2026-10-14 11:0x · 最高优先级）：**二创 → 定稿 → 落档。未过二创，不得定稿，不得落档。** 不可颠倒、不可跳过、不可事后补（补记＝违规）。

🔴 **定稿 7 项硬约束**（缺一即未定稿，不得落档）：稿头 `## 定题`／`## 标题二创`／`## 二创` 一行／`## 五查` 一行／Humanizer **实跑**（非口头）／母版比对做过／状态行在四项齐备之后。

🔴 **改动即失效**：定稿后改**任一处**（标题/正文/首评/标签/图内文案）→ 至少重过 Humanizer + 五查 + 母版比对；改动涉及**新增实质内容**（补数据/换论点/改结构）→ **六步全过**；并**同步图内文案 + 重渲**。

## 二 · 每篇必过质检清单（C02 §五 · 逐条）

- [ ] 稿头有 `## 定题` 一行（方向/红狐评分/候选排序/n/证据等级/数字依据）
- [ ] 稿头有 `## 标题二创` 一行
- [ ] 二创六步全过 ＋ 稿头留「二创」结论一行
- [ ] 同质化五查已跑 ＋ 结论一行
- [ ] 闸门 `P0 = 0`
- [ ] 字段一致性体检（稿 = 主表）
- [ ] 图序 `big → list → big`（`render(strict=True)` 通过）
- [ ] **图内文案已同步**（家数/日期/企业名/无绝对化用语）
- [ ] 标题 **≤20 字**、人群词前置、搜索词落前半段
- [ ] 正文 **300–600 字**（A 层时效稿可 200–400）
- [ ] 结尾**必须是问句**（禁总结陈词、禁预告）
- [ ] 首评 = **只提问不引导**，人群点名型，**与结尾提问错开**；🔴 **段名一律 `## 置顶首评`**（2026-10-16 起定为标准，**禁自创段名** —— 依 C35 §四·2；理由见 §五 表）
- [ ] 「不说全」：A 层只说 2–3 家最急的 / B、C 层列 3 留 2
- [ ] 表外企业**逐家核过**才写名字；**核不到宁可少写**
- [ ] 属性类结论（免笔试/无笔试/招往届/不限院校）**官网无明文 = 判 C 不落表**
- [ ] 待遇只模糊写（**禁**六险一金/十几薪/日薪 X/年薪 X 万）
- [ ] 学历门槛不写，或只写「对学校卡得没那么死」（**禁**二本能进/双非可投）
- [ ] 🔴 **改动即失效**：定稿后改任一处 → 重跑 Humanizer + 五查 + 重渲图，并同步图内文案
- [ ] （2026-10-16 新增）**无「领取」系诱饵 ✓ ｜ 无「求赞藏」系诱导互动 ✓**（五处都过）

## 五 · 内容纪律

> 出处：`03-内容与出图规范.md`（守则 35/41/48/55/59/61/62）＋ `01-铁律.md`

| 项 | 标准 |
|---|---|
| **标题** | ≤20 字（守则 62）；爆款公式 `{具体数字}+{今天/截止}+{汇总/可核验}`；🔴 **字数写法（C51 §五·3）**：一律写「**N 字符（去空格）／M 汉字**」，**禁单写「N 字」** |
| **正文** | 300–600 字（A 层时效稿 200–400）；**第一人称贯穿**；短句为主；少用符号分隔；**保留一个「我踩过的坑」** |
| **人称不漂移** | 正文叙事必须第一人称；封面/主标题可用第二人称；正文延伸的 list 图**跟随正文人称** |
| **收尾落回「我」** | 正文末句写「我」的立场/动作；**互动提问放「置顶首评」，不放正文末句** |
| 🔴 **首评段名（2026-10-16 定标准）** | 一律 **`## 置顶首评`**，**禁自创**。理由：五查 R3（首评前 10 字）**靠段名取首评**；段名自由 → 取不到 → **该红线静默失效**（v1 下 10-15／10-16 参照篇 `## 首评`、行内 `**置顶首评**：` 两种写法全部取不到，R3 从未真正生效，2026-10-16 由 C35 §二·5 实证）。**历史稿不改，留痕即可** |
| **收藏率**（守则 48） | 收藏÷观看 ≥ 点赞率；结尾加**功能型**收藏引导；禁「求收藏/收藏领取」 |
| **时段**（守则 41） | A 层 14:00–16:00 首选、B 层 17:30–18:30；**但时效型跟数据节点走（越早越好）** |
| **判据** | **读出来像不像人在讲自己的事** |
| **秋招称呼** | 统一「2026秋招」（守则 55，**不写「2027届」**） |

### 「不说全」纪律（留白 · 守则 6 之 6 步）

| 层级 | 留白方式 |
|---|---|
| A 层时效稿 | 今天截止 5–6 家 → **只说 2–3 家最急的**，其余写「整理在表里」 |
| B 层干货稿 | **列 3 留 2** + 结尾抛问题 |
| B 层往届生稿 | **说 3 家不说全部** + 带 1 家反例 |
| 所有层级 | **结尾必须是问题**（禁总结陈词） |
| 图片 | **不给全量数据**（封面只给核验样例） |

### 题材边界（守则收窄 · 2026-10-11）

**坐标系 = 「秋招网申投递」**。✅ 写：截止日/投递节奏/网申填表/信息核验/投了没回音排查/时间表工具。❌ 不写：面试技巧/群面/笔试准备/简历模板合集/offer 选择/职业规划/周报框架。
**判据**：**帮读者「把简历投出去」→ 界内；「投出去之后的事」→ 界外。**

### 内容配比（守则 35）

A 层信息型 60% / B 层方法论 40% / **C 层自我宣传 0%**。每条先答「读者今天为什么要看这条」。

## 七 · 交付与落档

### 7.1 发布包结构（每篇）

```
_协作/发布包/<日期>/
  笔记-XHS-<日期>-WB-<层>.md     ← 落档稿（含稿头 定题/标题二创/二创/五查/状态）
  图/<批次>_图N_<版式>.png        ← 3 张
  render_<日期>_<层>.py           ← 渲染脚本
```

#### 🔴 库存候选命名规则（C46 §二 追加 · 防「自撞」根因）

`_sim_check.py --recent` 只收 **`笔记-` 前缀**的文件作参照系 → **库存候选稿一旦用 `笔记-` 前缀就等于自己进参照系**，启用后必然与自己撞车（10-17 实测：正文 0.952／标题 1.000）。故：

| 阶段 | 命名 | 目录 | 是否进参照系 |
|---|---|---|---|
| 未启用 | **`库存-<日期>-<主题>.md`** | `发布包/库存候选/` | ❌ 不进 |
| 已启用（已复制为当日正式层） | **`已启用-<日期>-库存候选-<主题>（=<层>层，勿再作新批比对）.md`** | `发布包/库存候选/` | ❌ 不进 |

🔴 **禁用**：`笔记-` 前缀用于库存候选（会入参照系）。🔴 启用后**必须改名**，只留一份、不留别名副本。

### 7.2 桌面手机端包

```
待发包-<日期>-ABC层/
  A层-<题>/   { 文案.txt + 图1/2/3.png }
  B层-<题>/   { 同上 }
  C层-<题>/   { 同上 }
  00-先看这个.txt                 ← 清单（含实跑字数/闸门/五查/三层齐不齐）
```

### 7.3 硬纪律

- 🔴 **三层齐不齐自检**：缺层必须在 `00-先看这个.txt` 写明原因，**不许默认交齐**
- 🔴 **md5 对照而非目测**（发前终检标准动作）：桌面 ↔ 落档**逐一核对 md5**
- 🔴 **「已交付/已生成」必须回磁盘取证**（R8）
- 🔴 **M8 核验四件套**：①官网校招页 URL ②公告原文摘录 ③截图文件名 ④A/B/C 判定 —— **缺一不算核过**
- 🔴 **回写自证四件套**（主表）：version 递增／updated／changelog 追加／备份落盘 —— **缺一即视为未完成**
