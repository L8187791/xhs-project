## 二 · 评论回复钩子（每条必回 · 复制一条改改就发）

> 总原则：**说数量不说名字**、**每条抛回一个问题**（把对话留在评论区）、**不承诺结果**。
> ⚠️ 默认口径：**零引导**——不引导私信、不引导下单、不引导店铺（处罚期 10/12–10/19 纪律①不挂商品）。**若要改，回一句即可，我改模板。**

### 1. 报届别（我是 23 届 / 22 届 / 毕业两年了）
```
23届的话窗口其实比应届长一点，只是要一家家自己翻。你现在手上同时在投几家？
```

### 2. 问「我这情况还能投吗」（空窗俩月 / 待业 / 在职想换）
```
能不能投不看毕业几年，看那家公告的报名对象怎么写。你把届别和方向说下，我按类别回你。
```

### 3. 问「表在哪 / 怎么拿」
```
表这几天陆续整理出来。先给你个笨办法：招聘软件搜企业名，进它官网点「校园招聘」，看报名对象那栏写没写毕业时间，写了才算。你现在主投哪个方向？
```

### 4. 问具体企业（四川银行 / 光大那两家）
```
那两家我核到的是有出处的，一家分岗位放宽、一家报名截止日是公告上明写的。具体哪家收哪届我不敢替它写，你点官网「招聘公告」看报名对象那行最准。你更想投银行还是别的？
```

### 5. 抬杠 / 质疑（往届哪有优势 / 有空窗期怎么讲）
```
空窗期恰恰是你比应届能讲的东西多的地方，关键是这两年干了什么能不能说清楚。你是空窗，还是在职想换？
```

### 6. 纯情绪 / emoji / 「往届生破防」
```
一个人投就是这样磨人。不过卡住你的通常是投的那一个名字，不是你的本事。你现在投了几家了？
```

### 7. 问待遇（六险一金？多少薪？）
```
待遇那栏我不敢替它写，公告上怎么写就怎么算。你更看重薪资还是城市？
```
> 🔴 硬口径：待遇一律模糊，**禁**「六险一金 / 十几薪 / 包吃住 / 年薪 XX 万」；学历门槛**禁**「二本能进 / 双非可投 / 不限院校」。

### 8. 问学历门槛（二本 / 双非能投吗）
```
门槛高低得看具体岗位，我不敢替企业下结论。你把学历和方向说下，我按类别回你。
```
