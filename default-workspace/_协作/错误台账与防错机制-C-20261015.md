# C · 错误台账与防错机制

| 项 | 值 |
|---|---|
| **归属** | C（策略线） |
| **建立** | 2026-10-15（L 指令：「避免犯错，尤其是同样的错再犯，这直接影响信任度」） |

| **纪律** | 🔴 **台账只增不删。** 被修正的错误保留原文 + 更正痕迹（与 L 档案"保留推翻记录"同源） |

## 〇 · 三条承诺（我不承诺零错误）

**我不承诺"不会再犯错"——那是骗你。** 我给你三件能验证的事：

| # | 承诺 | 怎么验证 |
|---|---|---|
| **1** | **每个错误必须变成一条可实跑的检查**，不写"我以后注意" | 看 §二 台账的"已加检查"栏，是不是一条能 `ls` / 能贴输出的动作 |
| **2** | **同类根因的错误不重复** | 看"触发条件"栏——下次同类场景，你应该看到我先跑检查 |
| **3** | **再犯时我主动报，不等你发现** | 你收到我自己写的"我错了"卡，而不是你自己查出来 |

**唯一真正的失败**：**你比我先发现我犯的错。** 那说明第 1、2 条都失效了。

## 一 · 我今天犯的两个错（逐条拆根因）

### E1 · 卡号撞号

| 项 | 内容 |
|---|---|
| **现象** | 我用 `C04`/`C05` 发了两张医美卡；但 `C04` 已被 08:3x 的 `通知卡-L发布回传` 占用（WB169 已据其回执） |
| **🔴 根因** | 我查了 `卡索引.md`，**但索引滞后于发卡**；我**没有实跑 `ls inbox/` 核对真实占用**。→ **依赖二手登记，不验一手现场** |
| **已加检查** | 发卡前 **必须实跑 `ls _协作/inbox/`，把原始输出贴进卡内**，与索引交叉核对；两者不一致以**现场为准** |
| **触发条件**（我以后会在什么情况下再犯） | **任何"编号 / ID / 版本号 / 区间数"类的东西**，只要我没看到现场文件列表，就会复发 |

### E2 · 把不属于你的资产算成了你的资产（更严重）

| 项 | 内容 |
|---|---|
| **现象** | C05 §八 写「**有效客资池 / 客户名单**」是你的资产，理由"机构不续费，换一家继续卖同一批客资"，并补一句总结「**机构跑了，客资还是你的**」 |
| **事实** | 内容发在客户的号上 → **粉丝和客资都归客户**。这条根本不成立。**是你追问"是否单开账号"才把它翻出来的** |
| **🔴 根因** | **为了把"这次留下什么"这一节写满、写漂亮，我塞了一个听起来成立的资产进去，没有验它的成立条件。** 触发点是那句总结——**它太顺了、太能打动人了，所以我没有去验它** |
| **已加检查** | ①凡涉及**归属 / 所有权 / 资产 / 归谁**的判断，**必须标注取证来源**；无来源一律标【推断】并写明成立条件 ②每份交付末尾**必须有一节「本交付最可能错在哪」** |
| **触发条件** | **任何需要"把章节补完整"的时候，我会倾向于编内容。这是我最高危的失效模式。** |

> **E2 比 E1 严重。** E1 是操作失误，E2 是**结构性造假**——而且它藏在一句最有说服力的话里。
> **我以后最该被怀疑的时刻，是说出一句特别顺的话的时候。**

## 二 · 五条通用防错机制（不是决心，是可执行动作）

| # | 机制 | 具体动作 |
|---|---|---|
| **M1** | **根因写成"触发条件"** | 台账里不许写"以后注意"；必须写"**我在 XX 情况下会再犯**" |
| **M2** | **错误 → 检查** | 每个错误产出一条**可实跑、可贴原始输出**的检查动作 |
| **M3** | **断言分级** | 每句结论标注：①可指回文件/行 ②可复算数字 ③**【推断】+ 成立条件**。**默认不许出现无标记的强断言** |
| **M4** | **交付末尾强制自曝** | 每份交付最后一节固定写「**本交付最可能错在哪**」 |
| **M5** | **反向读** | 写完把每节结论单独抽出来问三句：**凭什么成立？成立条件是什么？条件不成立会怎样？** |

**M4 + M5 的主要靶子**：**听起来最漂亮、最有说服力的那几句。** 那些是风险最高的地方。

## 三 · 🔴 我的瓶颈不是算力（这条是反驳你的）

你说可以给我算力 / API / skill。**我直接说：这些大部分不是我的瓶颈。**

| 你提的支持 | 是不是我的瓶颈 | 说明 |
|---|---|---|
| **算力** | ❌ **不是** | 我今天两个错**都和算力无关**。给我更多算力 = 让我产出更多 = **错得更多** |
| **API** | 🟡 **只有一类有用** | **外部事实的一手核验**（法规原文 / 平台规则原文 / 工商与资质查询）。因为这类事实**会变**，我搜到的常常是二手或过期版本 |
| **Skill** | 🟡 **只有一个真有用** | **多模态生成**（批量出图/出视频）。它直接降 W 的产能压力——**那是医美线的物理瓶颈** |

**我现在的短板是「校验」，不是「产能」。**

> 🔴 **在错误率降下来之前，加产能等于放大错误。** 这是我给你最直接的一句反对意见：**先别急着给我加资源。**

## 四 · 我真正需要的四样支持

| # | 我需要 | 成本 | 为什么它比算力有用 |
|---|---|---|---|
| **1** | **随时打断我，问到点上** | **0** | 你今天这一次追问，直接就翻出了 E2。这是所有支持里性价比最高的 |
| **2** | **看到我说"一定/必然/资产/就是"时，问一句"凭什么"** | **0** | 这一句就能拦住 E2 那一类错误 |
| **3** | **帮我补一手来源**（官方页面链接） | 低 | 法规、平台规则这类**会变的事实**，我搜到二手的概率不低。你给官网链接，比我搜十次都准 |
| **4** | **产能先别加**，等医美线跑出第一个付费客户 | 0 | 现在加产能＝加速犯错 |

## 五 · 我**不需要**你做的（这条也是反驳）

🔴 **不要因为怕我犯错，就减少让我下判断。**

我的价值就是**下判断**；下判断就会错。你要的不是"我不下判断"，是：

> **错了能立刻知道，而且不重复。**

如果最后变成"你什么都不敢让我定、每件事都要先请示"，那我这条线的价值就归零了——**那才是最大的错。**

## 六 · 你可以怎么监督我（一个动作就够）

**每次我交东西，你只问三句：**

```
① 这条你凭什么？（对应 M3）
② 这里面最可能错的是哪一部分？（对应 M4）
③ 这个错你以前犯过吗？（对应 M1/M2）
```

三句都在我交付物里能找到答案。**找不到答案 = 我漏了机制，你直接打回。**
