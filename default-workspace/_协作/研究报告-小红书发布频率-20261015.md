## 一句话结论

> **最优解 = 2–3 篇/天，间隔 ≥3–6 小时，错开早/午/晚三个时段。**
> **我们现行的 3 篇/天（A 09:00 / B 12:30 / C 20:30）就是最优区间上沿，不用调。**
> 判"营销号"的触发器不是篇数，是**同质化 + 同时段连发 + 批量自动化特征**——这三样我们都有机制挡着（五查 / 间隔 / 不经 AI 手）。

## 2026 新规下真正判"营销号/批量"的四件事（多源一致）

1. **内容同质化（最高权重，一票标记）**：多账号/多篇封面文案相似度 >65% 直接判批量营销号；图文连滤镜、排版一致都触发降权
2. **IP/设备集群特征**：同一宽带批量发布、多号切换
3. **AI 托管批量养号**：2026 新规明确分级处罚——AI 辅助创作合规，**全程 AI 托管直接封禁**（发布不经 AI 手这条红线新规背书）
4. **重复铺货**：封面/文案/背景高度雷同的批量复制

→ 对应到我方防线：五查同质化检测 + 母版间隔 ≥3 天 + 排班表换讲法 ≥2 项 + L 手动发布。**四条全命中"安全侧"。**

## 对我方的三条行动结论

1. **节奏不动**：3 篇/天维持，别加量。我方实测 ≥5 篇 = 流量塌方，与外部"安全线 5 篇"互证。
2. **解禁后也不加量**：回暖周（10/19-26）仍 3 篇/天，把产能花在转化率修复（0.02%→0.25%），不是篇数。
3. **真正要守的不是篇数是间隔**：A/B/C 三篇的 09:00/12:30/20:30 分布恰好满足"间隔 ≥3-6h + 错开高峰"，这个排期本身就是合规最优结构，别为单日热点打乱。
