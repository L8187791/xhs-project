## 三 · 该库的知识体系（六大板块·据库内原文归纳）

### 1｜平台规则与类目（最完整、最有价值）
- **类目演进史**：身份证即可开店 → 2025 中旬「电子资料包」→ 2025 下旬升级为「**电子资源**」并上线官方自动发货；
- **2026-03-18 新规**（转载文含官方规则地址 `school.xiaohongshu.com/rule/detail/134/119724`）：**个人店不再可售「成人教育/儿童教育」类目**；4/2 生效、**4/15 前必须完成升级**，否则商品强制下架；
- **电子资源三个二级子类目**：①PPT/简历模板/其他模板 ②**课件·教案·手抄报** ③壁纸；
- **错放类目 → 商品冻结**；驳回时申诉话术：「我是原创内容，不是电子书，不是纸质书籍」。

### 2｜上架与合规
- 平台当前在打三点：**电子书 / 书籍 / 盗版资料**——标题与详情页须刻意避开「电子版书」表述，改走「可做教案课件」；
- **年销售额 > 10 万**须升级个体户并按季报税；
- **自然人代开发票**（山东·数电普票）**逐步操作流程**齐全（APP + 网页版、六项注意点：不能开专票、严禁虚开、劳务个税由付款方代扣等）。

### 3｜五条变现通道与取舍
| 通道 | 门槛 | 特点 |
|---|---|---|
| 店铺（电子资源类目） | 高（定向准入） | 官方自动发货，正规 |
| 教育类目 | 需教师资质 | 需执照经营范围含教育 |
| **个人售卖** | 极低（实名即可、0 保证金） | 发笔记挂组件、自动发货、买家确认后进支付宝 |
| **行家认证** | 邀请制/持续活跃 | **付款后可合法交换微信**、私信谈价+发起收款 |
| 达人分销 | 无 | 不办执照，但店铺不是你的、收益分成 |

### 4｜内容生产方法
- **两种提示词模式**：①直接指定输出形式（要 HTML 就直出 HTML→存 PDF）②投喂爆款让其分析题型再产出；
- **AI 强项 / 弱项**（库内明确给出）：宜做**总结归纳·基础识记·纯计算·计划清单·作文素材**；**避开**复杂奥数、主观题深度解析、教材原文默写填空；
- **HTML 直出防同质化铁律**：题型数要改（3 种→4 种）、题量要改（8 道→6 道）、大标题与排版都要变，可**融合多个爆款**。

### 5｜选题与差异化（方法论最系统）
- **对标「需求」而非「作品」**：样本库分**直接样本 / 替代样本 / 相关样本**三类；
- **七层需求验证**：时机 → 真爆假爆（比账号基线、看评论具体度）→ 动机（功能/时间/情绪/风险四价值）→ 缺口 → 小样 → 需求书 → 合规；
- **四向扩展法**：同人群换场景 / 同场景分人群 / 同任务换难点 / 单份资料→完整流程；
- **需求分层**：高频刚需（马上做）/ 中频潜力（逐步布局）/ **低频但高客单**（差异化）；
- 需求探测三法：**搜索下拉词反推热度**、**竞品评论区挖「求推荐/吐槽/确认」三类留言**、**相邻品类（育儿/教育博主）交叉**；
- **差异化定义**：「不是死于你做的不够好，而是死于别人记不住你」——要给用户**非买你不可的理由**，且**差异要有证据**。

### 6｜运营风控与心态
- **同质化三源**：搬运抄袭 / **模板同质化** / **自我重复**；同一份资料**间隔 3–5 天甚至 ≥2 周**再发；一天 **1–3 篇精品**优于 6–10 篇量堆；
- **图文可挂个人售卖、图片轮播不能挂**；不发「666/985/211 领取」类引导；
- **「真实感」>「精致感」**：AI 生成封面反而容易被划走，手搓封面/实话实说更受欢迎；
- 心态：前一个月「跪着」；不看小眼睛只看「每天一份资料+一篇笔记」；**后期护城河＝服务**（示例：把一个「口算丢分」问题研究透 → 由资料升级为可高价的诊断式服务）。
