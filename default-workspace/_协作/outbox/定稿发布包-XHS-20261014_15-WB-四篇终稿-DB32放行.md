**标题**（10 字 ≤20 ✓）
```
实习经历别写成流水账
```

**正文**（328 字 ✓）
```
网申填到实习经历那一栏，很多人卡住。不是没经历，是不知道怎么写。

我一开始也是流水账。「在 XX 公司实习，负责资料整理，协助部门日常工作」——写完自己都不想看第二遍。

后来改了一版，通过率明显不一样。差别就三点。

一处是：别写你做了什么，写你做成了什么。
「负责资料整理」改成「整理 3 个部门、200 多份合同，按到期日重建台账」。前者是谁都能写的一句话，后者是只有你做过的事。

第二处是：能用数字就用数字。
「协助提升效率」太空，「把周报整理时间从 4 小时压到 1 小时」就有画面。数字不用大，真实就行。想不起来确切数，写个范围也比含糊强。

第三处是：写和岗位相关的部分。
投银行，财务相关的经历往前放；投互联网，数据或项目的往前放。同一段实习，投不同岗位，重点可以不一样。别一段经历投遍所有岗位。

这三条不用全用上，挑你有料的一段改就行。

改完读一遍，问自己：这段话，换成另一个人写得出来吗？写得出来，就还得再改。
```

## 📅 10/15 B 层（17:30 发布）

**标题**（10 字 ≤20 ✓）
```
简历上这三件事别写
```

**正文**（306 字 ✓）
```
改简历的时候，删掉过一些东西。删完反而更容易过初筛。

第一件事是那些虚的自我评价。「吃苦耐劳」「学习能力强」这类，写上去没人会信，不写也不吃亏。不如换成一句具体的：做过什么，做完什么结果。

第二件事是把所有经历都塞进去。投银行和投互联网，看的是不同的东西。投银行的时候，一份校园活动策划的经历不如一段财务实习。同一段实习，投银行可以写财务细节，投互联网就写项目成果。与其全写上，不如按岗位删。

第三件事是写得让 HR 看不清你干了什么。比如「负责项目推进」——推进到什么程度？多少人的项目？做完了没有？

把动词换成能看见结果的说法。负责变成了完成，参与变成了主导哪一块。

我去年就是这样改的。删掉一半内容，留下能对应岗位的几条。

后来发现，简历这件事不是写得多，是写得对得上。

每条都对着它招的岗位看一眼，对不上的先删。

主页合集内有完整实操示例。
```
