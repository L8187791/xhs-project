## 二 · 三个 🔴 级问题（证据链 + 后果）

### 🔴 P1 · 主文档口径严重漂移，已经在给执行层发错地图

| 指标 | 主文档里并存的口径 | 冲突点 |
|---|---|---|
| **商品访客** | §0/§6.3/§6.3.1/§13 写"**已恢复可观测，四问可逐环定位**"（v4.10） | 🔴 **10-12 07:4x 豆包卡实测证伪**：「个人售卖端**仅成交量、无访客量**」→ **主文档未更新**，仍教执行层"访客=0 定位挂载问题" |
| **对外家数** | 142 / 131 / 111（已作废）/ 120（§4.0.1a 残留） | 四个版本并存，对外口径有合规风险 |
| **混合客单** | 88 / 58.3 / 51.5–59.5 | 三版并存，目标推导基数不定 |

**后果**：三方按不同版本作业 → 误差逐级放大；**最新一次观测前提变更（访客不可见）没有传导到主文档**，执行层会用一把失效的尺子量。
**根因**：v4.x 版本迭代 16 次，**只做"增量追加"，从不下沉历史值**——主文档已有大量"🔴已作废/⚠️历史口径"的括注，但正文仍在同页引用。

### 🔴 P2 · 转化被降级为"排在曝光之后"，但它才是唯一卡点

**计划的口径**（§2.7b）："现阶段主要矛盾 = 曝光不够；**一切向破 200 曝光倾斜，转化问题排在曝光之后**。"

**但数据不支持这个排序**：

| 事实 | 值 | 含义 |
|---|---|---|
| 近 7 日观看 | **4,469**（≈638/天） | 不是零曝光 |
| 封面点击率 | **16.7%**（大盘 5–10%） | **封面/选题没问题**（计划自己下的结论） |
| **成交** | **0** | 观看不低 + CTR 极好 → **"曝光不够"无法完全解释 0 单** |

**更严重的是**：中间环（进店/点击）**已确认不可观测** → 计划里"四问逐环定位"的行动框架**已失效**，但 §6.3.1/§13 仍在用它当行动指南。
**后果**：把转化排在曝光之后 + 用失效的定位框架 = **曝光涨了也不知道转化行不行，可能越投越漏**。
**关键提醒**：**12 月目标 10,000–20,000 元 = 191–220 单/月 = 6.4–7.3 单/天**（需当前观看量约 4 倍），**而这个增长建立在"转化率未知"之上（0 样本）**。目标可不删，但**必须标注"未验证"**，不能当锚。

### 🔴 P3 · 组织过重 + 双店分心，产能被协作机制吃掉

| 信号 | 事实 |
|---|---|
| 服务规模 | 551 粉（其中 500 为冲量）/ **0 单** |
| 运营系统 | 1,600 行主文档 + 3 AI + 每日提请/裁定/交付/回执卡片往来 |
| 双店并行 | B 店（考公）方案**自己承认**"会压垮三个环节：WB 日产、豆包必审、用户发布" |

**后果**：产能花在"协作机制"而非"卖货动作"；**B 店在 A 店漏斗未验证前铺开 = 复制一个还没跑通的模式**。
**这不是说不该做 B 店**，而是**顺序错了**——B 店应是"A 店首单验证成功后的复用"，不是"并行试错"。
