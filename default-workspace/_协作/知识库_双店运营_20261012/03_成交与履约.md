# 03 · 成交与履约（v1 · 2026-10-12）

## 一、两条成交体系（必须分清）

| 维度 | 个人售卖（App 内） | 店铺（千帆） |
|---|---|---|
| 开通门槛 | 注册满 30 天 + 实名，0 保证金 | 开店 + 「电子资源」定向准入许可 |
| 上架复杂度 | 发笔记时「添加组件」挂链接，无需加类目 | 需特殊许可 |
| 交付 | 网盘链接挂上、拍了自动发货 | 常规商品流程 |
| 回款 | 约 3 天到实名支付宝 | 7+7 |
| 流量 | 走自然流，据反馈可能比挂商品还大 | 店铺商品页 |
| 限制 | 单笔记单链接、无多 SKU、看不到销量/评价、无评论区蓝链/直播挂链 | — |
| 数据可见 | 手机 App「专业号」后台可见 | 千帆后台 |

> 电子资源类目准入（店铺侧）：注册满 180 天 + 粉丝 1000 + 近月流水 6000，需同时满足。个人售卖不需要。

## 二、上架动作链（个人售卖 / 挂链）

1. 资料放进网盘**新建文件夹**，生成分享链接；
2. **开「分享链接自动填充提取码」**——客户收到后复制链接直接打开，无需填提取码；
3. 发笔记时「添加组件」挂链接（单笔记单链接）；
4. 客户拍下 → 自动发货。

## 三、客服纪律

| 规则 | 标准 |
|---|---|
| 24h 回复率 | 24 小时内必须回复客户，否则罚款；做「最后一个说话的人」；智能客服回复、真人回复均可 |
| 退款 | **能退就退，不纠缠**；直接同意，不解释不挽留——差评对评分伤害 >> 一单损失 |
| 防白嫖 | 同一用户「反复购买→退款」≥2 次才拉黑；一次性退款不拉黑（防误伤真实用户）|
| 售后拒绝率 | 有 6 类不计入考核场景（仲裁判非商家责任、客户主动撤销、已签收主观原因仅退款等）；其余正常计入 |
| 咨询原则 | 不过分夸大、说实话；资料好 = 退款少 |

## 四、定价逻辑

- 起步测款：低价档起步（如 3.9–5.9 区间逻辑适用于低客单图文类），**出单后再调高**；多种合集的合集可更高价。
- 本项目的哑铃：时间表类 19.9 + 全流程包 99，中间档不做。
- 评估节奏：D30（11/9）实测转化率后再评估是否往 39–99 走；过早调价扰动实验。

## 五、履约补充

- 交付件三层：免费 PDF + 免费 Skill + ¥19.9 档。
- 99 包首屏必须回答「为什么不是 19.9」：交付清单具体到「5 份资料 / 40 个文件 / 11.21 MB / 含 zip / 含一次定制化改写」。
- 更新时间表走固定 SOP（每周核验 + 更新），做成可续费商品是后续选项（暂不做）。
