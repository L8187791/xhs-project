# 07 · 协作纪律与回答五规则（v1 · 2026-10-12）

## 一、三方协作协议（发卡-接卡-回卡）

- **运营官（豆包）**：读卡 → 审核（主文档口径 + 竞品规格基准）→ 出裁定卡/催卡 → 更新监听索引；只读写 _协作 目录及主文档。
- **内容生产（WorkBuddy）**：接卡执行 → 交付卡回传（含自检表）→ 更新卡索引。
- **执行人（用户）**：拍板 + 平台操作（上架/发布/扫码/后台数据回传）。
- 命名规范：`交付卡/裁定卡/告知卡-平台-日期-角色-编号-主题.md`。
- 监听索引：记录已处理卡名，避免重复处理；定时任务按索引推进。

## 二、回答五规则（固化纪律，适用于所有对外内容）

1. **可核验事实**：回答必须全部是可公开核验的事实，禁止编造；不确定的内容直接说不知道。
2. **原创重述**：内容尽量原创重述，不直接复制原文；引用外部来源用 MLA 格式标注。
3. **表达风格**：介于学术正式和日常口语之间；每句话有明确主语，语句完整。
4. **事实/猜测分离**：回答完成后区分事实和猜测部分；删除所有无法查证的内容。
5. **遵守全规则**：收到清晰提问时，严格遵守以上全部规则作答。

## 三、数据纪律（内容生产与审核通用）

- 每个数字必须来自输入、具体信源或可复现计算；否则标为待补充或估算并写明口径。
- 汇总由明细现算，排序由分值现算；同一数据跨产物并排核对。
- 外部事实附可追溯来源，区分「已查证」与「一方称」。
- 来源等级 + 核验日期两列纪律，适用于所有时间表类产品。
- 家数口径：对外 131 / 内部 142 / 作废 111——只写对外口径。

## 四、决策纪律（重大决策三步唱反调）

1. 全力反驳：找风险 / 认知偏差 / 不可逆成本 / 机会成本 / 最坏风险；
2. 支持视角：列核心理由；
3. 中立对比：证据判断哪边占优，指出最大未知风险与结论反转条件；拒绝强行五五开。

## 五、执行边界

- 只读写 `_协作\` 目录及作战计划主文档，不动其他文件。
- 未拍板不代拍（启动时间、定价、人设名等属执行人权）。
- 越界自检：每轮交付前核对是否动了不该动的文件/口径/代码。
