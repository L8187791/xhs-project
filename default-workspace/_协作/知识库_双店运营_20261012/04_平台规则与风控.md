# 04 · 平台规则与风控（v1 · 2026-10-12）

## 一、同质化判定（核心红线）

**触发条件**：同 WiFi + 相同模板内容批量发 / 多账号发同一份资料 / 一店原创发另一店。

| 判定项 | 隔离标准 |
|---|---|
| 赛道主题池 | 两店选题池零重叠 |
| 标题句式 | 逐字不同（A 店「N月N日起N天｜N家」已占用，B 店换新句式）|
| 封面版式 | 页眉名/配色/字体/布局整套不同 |
| 正文骨架 | 清单型 vs 叙事型，段落结构不同 |
| 首评话术 | 两店互不出现对方首评句及变体 |
| 数据源 | 独立官网核验，不共用数据文件 |
| 资料库 | 物理隔离，不共用 PDF/图/排版母版 |
| 设备 | 电脑 A↔A 店、电脑 B↔B 店、手机各挂一个、不混登 |

## 二、儿童形象红线（图文类）

- 手抄报/学习资料类**最好不要出现儿童形象**；出现也必须是玩耍/奔跑/运动等正向画面，禁止孩子干活、抱麦子等——易判「利用儿童形象玩梗，不当利用儿童形象」。

## 三、AI 内容规则

- AI 生成内容**不能直接发布**：相似内容易判同质化/违规，必须更换内容题材后再发。
- 提示词母版仅作学习用，不直接发布。

## 四、私域风险（已裁定：不碰）

- 各平台 2025 起收紧私域导流；主动加人超 5–10 个/天、被动加超 20–30 个/天、发收益截图、拉群都可能被限制甚至判诈骗。
- 平台打击引流 → 封号 → **实名身份证无法再注册平台**（不可逆损失）。
- 结论：**平台内成交闭环（个人售卖挂链/商品卡）**，不留微信、不导私域、不拉群。
- 信息储备（不执行）：公众号是唯一能直接留微信的平台；微信养号一周、闲鱼分价格链接收款——仅作认知，不落地。

## 五、版权红线（最高优先级）

- 搬运风险链条：没人发现 → 被发现未行动 → 平台举报 → 钓鱼资料（等法院传票/私下 2k-5k 解决）→ 刑事风险。
- 视频课程不碰；带机构 logo 的电子书不碰；无版权标识的个人总结可浅尝；最优解 = 自己做原创、独立版权。
- 国家层面 2025 下半年起版权监管收紧，各平台打击搬运是长期趋势。
- 维权通道：权利保护中心 ipp.xiaohongshu.com；裁判文书网可查判例（评估风险用）。

## 六、账号关联与多店规则

- 一个身份证可注册两个账号、都能开店（内测阶段），但两号存在隐性关联：**一个号违规可能波及另一个号**。
- 不同实名主体 = 实名层隔离：违规传染面从身份证层降到网络/设备层，收款各进各卡。
- 同 WiFi 非违规点；**同 WiFi + 同模板批量发 + 同设备混登**才是高危组合。
- 更稳的多账号打法：一个店关联 3 个普通账号（一拖三）——本项目已否（个人售卖号开不了店铺关联，且已拍板不做矩阵）。

## 七、闸门红线词与发布自检

- 闸门红线词 P0=0、P1=0；成稿 2 篇非空跑。
- 发布前六项核验：正文逐字≡校验文件、标签逐字+数量、图 >5KB、当日版 PDF 在位、首评文件两份、闸门非空跑。

## 八、其他运营细节

- 退款处理、24h 回复率考核（见 03）。
- 小红书记为草台班子，客服答复仅作参考；打三次「转人工」可跳人工客服。
- 出图脚本 account 隔离：note 加 account 字段优先、缺省回落全局；禁直接改全局 _account_name.txt（两店脚本各自写死页眉）。
