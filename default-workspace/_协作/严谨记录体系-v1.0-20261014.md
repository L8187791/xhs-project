# 严谨记录体系 v1.0

> **建立时间**：2026-10-14 20:5x ｜ **建立人**：W（WorkBuddy）｜ **触发**：L 指令「给我们的工作严谨记录做一个规划」
> **一句话定位**：本体系不增加新工作，只把**已经做过但没留下证据的动作**变成**可追溯的记录**，让同类错误第二次发生时能被立刻认出。
> **适用范围**：W / D / L 三方全部动作。**记录本身也是动作，回磁盘取证后再写，不得凭记忆填**（R8）。

## §3 怎么记：统一六字段模板

```
| 时间 | 事件 | 证据（可实跑路径/命令/原文） | 结论 | 责任人 | 状态 |
```

- **证据栏必须可被别人重跑**：写 `_协作/xxx.csv` 这种路径、或命令原文；写「我核过了」「应该没问题」＝**无效记录**。
- **结论栏必须跟证据自洽**：证据说 40% 准确，结论就不能是「可以发」（E6 的反面）。
- **状态栏三选一**：`已闭环` / `待复查（日期）` / `未闭环`。

## §4 八条硬纪律

| # | 纪律 | 违反后果 |
|---|---|---|
| **R1** | **无证据不落结论**。拿不到依据就写「无法查证 + 待确认」，不填默认值 | 按误判处理，等同 E2 |
| **R2** | **结论必须受数据约束**。数据与结论不自洽 → **直接退回，不采纳结论**（M7） | 退回重做 |
| **R3** | **改口必记依据等级** S/A/B/C；**C 级不得推翻 S/A 级** | 强制回滚 |
| **R4** | **自己的误判自己记**，且**记根因不记借口**（对照 E1/E2/E3 三条根因） | 由 W 主动撤回并留痕 |
| **R5** | **交付物实跑比对后才验收**，不采信自报数字（字节数/行数/列数必查） | 拒收 + 记拒收原因 |
| **R6** | **拒收也要留痕**：记文件名 + 拒收原因 + 要求补什么 | 避免「交了但没交成」的扯皮 |
| **R7** | **例外必须编号**（`EX-YYYYMMDD-NN`）+ 写明**豁免范围** + **复查日期** | 无编号的例外＝不成立 |
| **R8** | **记录本身不得凭记忆填**，回磁盘/日志取证后再写 | 按误判处理 |

## §6 复查机制

| 频率 | 动作 | 谁 |
|---|---|---|
| **每日 22:00** | 复盘时**抽 30% 记录回磁盘复跑**，看证据能否重现 | W |
| **每周** | 清一次 `待复查` 项，未闭环的升级为待办 | W |
| **例外到期日** | EX 编号到期**必须复查并写闭环结论** | W 报 L |

> 抽查原则：**查的是记录能不能被重跑，不是查结论好不好看**。重跑不出同样结果＝记录无效。
