# 归档同步（守则 30）

## 位置
`D:\Documents\deepseek-harness\default-workspace\小红书项目_归档同步.py`

## 用法
```bash
python 小红书项目_归档同步.py
```
- 源：`D:\Documents\deepseek-harness\default-workspace`
- 目标：`D:\小红书项目`
- 记录：`D:\小红书项目\00_归档同步记录.md`（每次追加一行：新增/更新/总量）

## 特性
1. **增量同步**：只拷有变更的文件。
2. **自动分类**：按 `DIR_MAP` 映射（如 `_协作\` → `05_协作记录\`，`日报\` → `01_每日运营\日报与复盘\`，`竞品监测\` → `06_竞品与市场\`）。
3. **排除**：`.xhs_profile*`、`.ark_profile`、`.tools`、`.tmp`、`__pycache__`、`.workbuddy`、`node_modules` 等。

## ⚠️ 两个已知坑
1. **根目录未映射的 md 只告警、不复制** —— 脚本会输出「⚠️ 未映射文件: xxx」。这类文件若需归档，**手动复制到对应分类目录**（如总纲类 → `D:\小红书项目\00_总纲与计划\`）。
2. **产出校验不能只看「文件存在」**（守则 2.4）：归档后核对同步记录的时间戳与新增条数。

## 验收
- 每次收卡/发卡后跑一次；**每张任务卡都要写这条要求**（守则 30）。
- 同步后 `D:\小红书项目\` 与工作区一致；例外项（未映射文件）在交付卡里说明去向。

## 边界
- 只做单向增量同步（工作区 → 归档），**不删目标侧文件**。
- 不改动被同步文件的内容。
