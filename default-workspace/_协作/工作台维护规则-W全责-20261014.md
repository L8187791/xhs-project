## 四 · 写入纪律（沿用 MEMORY §11，不可省）

1. **properties 必须带类型键**：`{"状态":{"select":"已发"}}`；裸值会被拒；**误用 text 写 select 会冲成空值**。
2. **写表 = 云端直接写，不走事务协议**；**改页面 HTML 才走事务协议**（字节级 `rb`/`wb`，文本模式会把 LF 改 CRLF 造成越界）。
3. **回读验证**：批量接口返回 `success:true` **不代表落库**，必须 `get_database_content` 回读确认条数/内容（本次 4 条新增、9 条更新均已回读验证）。
4. **未回传不填**：数据类字段没拿到就留空，不编、不推测（守则 47）。
5. **不改表结构除非必要**：加字段可以；**删字段 / 改字段类型 / 批量删记录 = 不可逆，必须先问 L**。
6. **QPS**：单表 30 QPS，连续调用后停一下，不刷单表。
