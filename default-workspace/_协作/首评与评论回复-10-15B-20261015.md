## 二、评论回复钩子（每条必回 · 复制对应一条改改就发）

> 总原则：**说数量不说名字**、**每条都抛回一个问题**（把对话留在评论区）、**不承诺结果**。
> ⚠️ 默认口径：**零引导**——不引导私信、不引导下单、不引导店铺（处罚期 10/12–10/19 纪律①不挂商品）。**若你要在回复里指向店铺/商品，需你先拍板**（属「发不发」类决策，我不自行决定）。

### 1. 报了大厂名字 / 问「我想进 XX，它下面有啥」
```
这类我表里收了十几家，名字我就不在这儿全放了。你搜「XX 生态链」往下翻，翻到不认识的点进去看岗位和要求就行。你现在投的是研发还是运营？
```

### 2. 报了卡点（简历 / 网申 / 没回音）
```
卡在这一步的人其实最多，不是你一个人。你是投完没回音，还是填到一半放弃了？
```

### 3. 卡在笔试 / 面试
```
这关这批也一样跑不掉，只是同样的准备投这儿更划算一点。你卡的是行测还是专业面？
```

### 4. 问「表在哪 / 怎么拿」
```
我这几天会陆续整理出来发。先给你个笨办法：招聘软件里搜大厂名字，往下翻它投资和控股的公司，或者搜「某某生态链」，能翻出一批。你是投哪个方向的？
```

### 5. 抬杠 / 质疑（「不就是外包吗」「子公司待遇差」）
```
确实要看是不是全资还是参股，这个你说得对。你更在意公司名字，还是岗位方向对不对口？
```

### 6. 纯情绪 / emoji / 「同双非破防」
```
是挺磨人的。不过卡住的通常是投的那一个名字，不是你的本事。你现在主投哪个方向？
```

### 7. 问具体待遇（六险一金？多少薪？）
```
待遇那栏我不敢替它写，公告上怎么写就怎么算。你更看重薪资还是城市？
```
> 🔴 硬口径：待遇一律模糊，**禁**「六险一金 / 十几薪 / 包吃住 / 年薪 XX 万」；学历门槛**禁**「二本能进 / 双非可投 / 不限院校」。

### 8. 问「双非到底能不能进」
```
门槛低不等于随便进，笔试面试一样跑，这点我不骗你。你目前投了几家了？
```
