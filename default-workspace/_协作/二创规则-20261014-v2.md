## 四 · 第 6 步 · 留白纪律（**执行说明**）

**与既有纪律同源** —— 本步 = 项目已有的「**不说全**」纪律：

| 层级 | 留白方式 |
|---|---|
| A 层时效稿 | 今天截止 5–6 家，**只说 2–3 家最急的**，其余写「整理在表里」 |
| B 层干货稿 | **列 3 个，留 2 个不说** + 结尾抛问题 |
| B 层往届生稿 | **说 3 家不说全部** + 带 1 家反例 |
| **所有层级** | **结尾必须是问题**（禁总结陈词） |

**图片留白**：封面/内页**不给全量数据**（沿用 v4.31 封面留白口径：只给核验样例 + 部分真实数据，完整明细留商品）。

**四好处**：保基本价值 / 留缺口（想买完整版）/ 关注钩子（等更新）/ 互动钩子（评论问）。

## 五 · 母版参照系与排期红线（沿用 v4.28 / v4.30）

### 5.1 母版参照系（**易错点**）

🔴 **参照系 = 最近 3 天内已发的所有篇** + 同日前序稿，**不是**只锚最早的爆款。

- 犯过的错：只拿 10-11《本周12家》当母版，漏了 10-13 刚发的《网申填表 5 细节》→ 撞题被退回
- **动作**：出稿前先列最近 3 天产物清单，逐一比对

### 5.2 排期红线

| 红线 | 值 |
|---|---|
| 同母版切口间隔 | **≥ 3 天** |
| 形式变换 | **至少换一次**（标题版式 / 封面版式 / 内容结构） |
| 母版豁免 | 母版非「烂大街」不在打击范围 |

### 5.3 🔴 分层裁定（L 2026-10-14 11:2x 拍板 · 覆盖 5.2 的一刀切）

| 层 | 「隔 3 天」是否豁免 | 替代约束（不豁免则必须满足） |
|---|---|---|
| **A 层时效稿** | ✅ **豁免** | 🔴 **但必须按《A层时效稿防同质化排班表》换讲法 ≥2 项**（信息角度/结构/开篇钩子/结尾提问/留白位置），并填排班表；**填不出 = 不许定稿** |
| **B 层机会型** | ❌ **不豁免** | 同方向 ≥3 天；且**不得与相邻日 B 层同向连用** |
| **C 层往届生** | ❌ **不豁免** | 同方向 ≥3 天 |

**为什么 A 层豁免**：时效稿讲的是"今天/明天要截止的企业"，企业重复是天然且合理的（今天预告 → 明天真关），强求间隔等于取消日更。真正要防的不是"讲同一批企业"，是"**用同一种讲法**"。

**一次性破例**：L 同批裁定 **10/15 三篇（A/B/C）破例放行**（因已成稿且 B 层已改讲法）。破例仅限 10/15，**B/C 层「隔 3 天」自 10/16 起严格执行**。

🔴 **五查（文本相似度）测不出切口撞车** —— 换掉企业名数值就掉，但同角度连讲两天它照样放行。**母版比对必须人工另做，五查不能替代。**（教训来源：10/16B 换企业后五查 0.031→0.014 看着安全，实则与 1014B 同母版且隔 2 天）

## 六·五 · 同质化五查（**L 2026-10-14 选 A 方案 · 与六步并行**）

> 六步解决「怎么写」，五查解决「是不是跟已发的太像」。**两者都要过。**

**执行时点**：六步第 5 步（Humanizer）之后、交付卡落盘之前。

**命令**：
```
python _sim_check.py --new <新稿1.md> <新稿2.md> <新稿3.md> --recent 3
```

**五项与阈值（店内 · 依跨店同质化红线 R1–R5）**：

| # | 项 | 🔴 | 🟡 |
|---|---|---|---|
| R1 | 正文 3-gram Jaccard | ≥0.35 | 0.20–0.35 |
| R2 | 标题 Jaccard | ≥0.30 | 0.15–0.30 |
| R3 | 首评前 10 字 | 逐字相同 | 前 6 字相同 |
| R4 | 正文开头 12 字 | 逐字相同 | 前 8 字相同 |
| R5 | 结构签名 | 与参照系 ≥3 篇同 | =2 篇同 |

**参照系** = 最近 3 天已发所有篇（同二创 §五 母版参照系口径），不是只锚最早爆款。

**交付卡一行格式**：
```
同质化五查：正文0.080/标题0.037/首评10=-/开头12=-/签名=有同 → 🟡
```

**处理**：🔴 必须改到 ✅ 才交付；🟡 在交付卡标注，由 L 决定是否放行。

> 🔴 **【强制（L 2026-10-14 固化）】**：本五查与上方六步为**每篇强制**，缺一不可交付——两步结果（`二创：…` 一行 + `同质化五查：…` 一行）**均必须写进交付卡**。五查不阻断**发布**，但阻断**交付**（查不过不许出卡）。

## 七·五 · 🔴 定稿 / 落档前置条件（L 2026-10-14 11:0x · 新增）

### 1. 三个动作的定义（先定义死，否则无法执行）

| 动作 | 定义 | 物理位置 |
|---|---|---|
| **二创** | 六步（§二）全过 + 五查（§六·五）跑过，且两条一行结论已落盘 | 稿头 `## 二创` 行 + `## 五查` 行 |
| **定稿** | 稿件被标记为最终版、不再改动 | 稿头出现 `**状态**：定稿` |
| **落档** | 写入发布包目录 + 卡索引 + 桌面手机端包 | `_协作/发布包/<日期>/`、卡索引、桌面 `待发包-*` |

### 2. 硬约束（缺一即视为**未定稿**，不得落档）

| # | 约束 | 验证方式 |
|---|---|---|
| **1** | 稿头必须有 `## 二创` 一行（母版=…｜步骤1-6=过｜Humanizer=已跑｜留白=是） | 无此行 = 未过二创 |
| **2** | 稿头必须有 `## 五查` 一行（正文x/标题x/首评/开头/签名） | 无此行 = 未过二创 |
| **3** | Humanizer **必须实跑**（非口头声称、非事后补记） | 交付卡须记改动处数 |
| **4** | 母版比对做过（最近 3 天清单，非只锚最早爆款） | 二创一行里写明母版 |
| **5** | 状态行 `**状态**：定稿` 只能出现在以上四项齐备之后 | 顺序可回溯 |
| **6** | **（10/15 起）** 稿头必须有 `## 定题` 一行（方向/评分/候选排序/n/证据等级/数字依据） | 无此行 = 未过定题 → 不得定稿（L 12:1x） |
| **7** | **（10/15 起）** 二创一行末尾含 `标题二创=T1~T5 过` | 无标注 = 标题未过二创（L 12:1x） |

### 3. 🔴 改动即失效（本条最易犯）

**定稿后任何改动 —— 标题 / 正文 / 首评 / 标签 / 图内文案 —— 一律使二创状态失效**，必须重过才能重新定稿：

- 重过范围：**至少** Humanizer（第5步）+ 五查 + 母版比对
- 若改动涉及**新增实质性内容**（补数据、换论点、改结构）→ **六步全过**，不是只补两项
- 🔴 **禁止"先落档再补二创"**：已落档的稿发现未过二创 → 退回未定稿状态，补做后重新落档

> **已犯案例（2026-10-14）**：10/15 A 层改标题/首评/结尾/补广发方向后、10/16 B 层改「一次→一场」「金融数据→数据运营」后，**均未跑 Humanizer 即落档** → 违反本条，本轮补做。

### 4. 落档前最后一道自检（W 每次落档前机械执行）

```
□ 稿头有二创一行？        □ 稿头有五查一行？
□ Humanizer 实跑并记了改动？ □ 母版比对做过？
□ 状态行写了「定稿」？      □ 本次改动后是否重过？（改动即失效）
```
任一项为否 → **不得落档**，退回补做。
