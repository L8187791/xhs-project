## 五、v2.1 校正后的策略调整

### 🔴 立刻要改的 3 件事

1. **内容配比大转向**：截止提醒 70% + 方法论 20% + 产品种草 10%
   - 依据：截止提醒类曝光是方法论类的 7.5 倍
   - 砍掉：《网申填表5个细节》《五种求职服务别急着买》这类方法论

2. **修复转化链路**：
   - 笔记结尾必加商品引导：「完整时间表在左下角商品里，持续更新」
   - 商品页信息密度升级：功能点+数据+社会认同

3. **少发精发**：每天1-2篇精品，不为日更而日更
   - 近7日发了19篇，但只有2篇爆了
   - 大部分都是长尾（曝光<500）

## 五、工作台优化建议（给 WorkBuddy）

### 当前工作台的问题

| 问题 | 为什么是问题 |
|---|---|
| 缺少「获赞与收藏」指标 | 这是账号健康度核心指标，比粉丝数更重要 |
| 缺少「笔记明细」板块 | 只看总发布数没用，要看每篇笔记的数据（浏览/点赞/收藏）才能判断什么内容好 |
| 待办清单没有按优先级分组 | P0/P1/P2 混在一起，不知道先做哪个 |
| 缺少「昨日复盘」板块 | 每天复盘的结论没地方放 |
| 缺少「竞品动态」板块 | 我们需要持续跟踪竞品，没有地方记 |

### 优化后的工作台结构（建议）

```
顶部状态条
├── 阶段：处罚期第 X 天（至 X/XX）
├── 数据时效：更新于 X/XX XX:XX
├── 产品状态：L1在售 / L2 X/XX上架 / L3暂缓
└── 数据源：已连接 / 待更新

第一行：北极星 + 处罚倒计时
├── 唯一北极星：30天19.9卖30单（当前 X/30）
└── 处罚倒计时：剩 X 天

第二行：店铺脉搏（6→8 个指标）
├── 粉丝数
├── 获赞与收藏 ← 新增
├── 累计成交单量
├── 店铺分
├── 昨日发布篇数 ← 新增
├── 昨日总浏览 ← 新增
├── 待办未完成
└── 对外家数

第三行：产品与价格档（不变）
├── L1 · 时间表 ¥19.9（在售）
├── L2 · 半年全套 ¥49.9（X/XX上架）
└── L3 · 全流程包 ¥99.9（暂缓）

第四行：昨日笔记明细（新增）
├── 笔记1：标题 | 浏览 X | 赞 X | 藏 X | 评论 X
├── 笔记2：标题 | 浏览 X | 赞 X | 藏 X | 评论 X
└── 数据最好的一篇：标题（为什么好）

第五行：运营待办（按优先级分组）
├── P0 必做（3条）
├── P1 重要（5条）
├── P2 可缓（10条）
└── 已完成（勾选）

第六行：昨日复盘结论（新增）
├── 今天做对了什么
├── 今天做错了什么
├── 明天最重要的一件事
└── 需要用户拍板的事
```
