## 二、🎯 最重要的发现：**点赞最高的不是信息型，是情绪型**

把实测数据按赞数排开，规律非常刺眼：

| 类型 | 例子 | 赞数 |
|---|---|---|
| **纯情绪 / 口号型** | 「秋招截止好快啊」 | **4545** |
| | 「大家记得投中小公司啊」 | **2289** |
| | 「逼自己投完吧，会有offer的」 | **1021** |
| **信息型（带日期/清单）** | 「10.1这么多北京秋招要截止了吗」 | 342 |
| | 「十一后截止的秋招网申」 | 198 |
| | 「先把10.7前截止的秋招投完吧」 | 134 |
| | 「2027届秋招网申信息汇总（10.7版）」 | **63 / 29** |

### 三条推论

**推论 1：情绪型吃"共鸣流量"，信息型吃"收藏流量"**
- 情绪型 → 大家有同感 → **点赞**
- 信息型 → 有用 → **收藏**（但未必点赞）

**推论 2：🔴 所以"按点赞排 Top10"会误导我们**
点赞榜前排全是情绪型，而**我们的产品要的是收藏与购买意图**。
→ 这正好印证 SOP 里那条加权分设计（**赞×1 + 藏×2 + 评×3**）的必要性。

**推论 3：⚠️ 但情绪型多数碰红线**
- 「逼自己投完吧」→ 情绪压迫
- 「免笔试」→ 结果暗示
- 「秋招截止好快啊」→ **这条相对安全**（纯感叹，无日期、无引导）

> **结论：情绪型能爆，但不能学。信息型不爆，但能转化。我们要走信息型。**

## 三、📐 格式卡（真实数据修正版）

### 🎴 卡 A · `{具体日期} + 截止 + 对象` ★★★★★ 最高频

**实测证据**（4 个长尾词里都出现）：
```
截止10.9还能投的银行秋招            122赞
10.9先把这些要截止的银行秋招投完啊啊啊  63赞
先把10.7前截止的秋招投完吧           134赞
10.1 这么多北京秋招要截止了吗😭      342赞   ← 本类最高
```

| 项 | 内容 |
|---|---|
| **句式** | `{日期} + 截止/还能投的 + {对象}` |
| **可直接套的例句** | ① 「10.10 截止的银行网申，我核了这 13 家」<br>② 「10月中旬前截止的央企，逐家核过官网」<br>③ 「还能投的国企秋招（10.10版）」 |
| **为什么有效** | **具体日期 = 时效性 = 可核验**，用户一眼判断"跟不跟我有关" |
| **与我们的兼容性** | 🟢🟢 **天然兼容** —— 我们的核心资产就是"逐家核验"，正好填进"日期"这个位置 |
| **判定** | ✅ **可立即套用，且应设为主力句式** |

> **关键**：竞品用这个句式时**给不出核验来源**。我们加上「逐家核过官网」，同样的句式就变成**别人抄不走的版本**。
