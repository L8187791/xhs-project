## 〇、先说结论：竞品标题的 4 种有效结构

从 8 家账号的爆款标题里，我提取出**4 种反复验证有效的句式**：

| # | 句式 | 验证案例 | 点赞 |
|---|---|---|---|
| 1 | `{群体}{主题}截止时间节点汇总` | 小王啊「银行秋招网申截止时间节点汇总」 | **1189** |
| 2 | `{时间锚点}后要截止的{对象}真的很多` | 国聘求职「国庆假期后要截止的秋招真的很多」 | **1493** |
| 3 | `{细分方向}{N}家` | 喵中求职日记「财经79家」「银行管培40家」 | — |
| 4 | `{主题}（{日期}版）` | 薯条派 9.17→10.9 版本化日更 | — |

**注意**：句式 2 是**我们唯一不能直接用的**（情绪+紧迫，碰红线）。下面逐张说明。

## 🎴 格式卡 1 · 截止节点汇总型

**验证强度**：★★★★（1189 赞，来自 664 粉小号 → 可复制性强）

| 项 | 内容 |
|---|---|
| **标题句式** | `{群体}{主题}截止时间节点汇总` |
| **可直接套的例句** | ① 「银行秋招网申截止时间节点汇总」<br>② 「央企校招网申截止节点汇总」<br>③ 「国企秋招截止时间节点汇总（10月版）」 |
| **封面版式** | **表格截图** — 三档标色（红=7天内 / 橙=8–15天 / 灰=已截止） |
| **正文骨架** | ① 结论前置：最紧迫的 3 家（含剩余天数）<br>② 按剩余天数分组的清单<br>③ **边界声明**：覆盖 N 家、不是全部、来源分级<br>④ 提问式收尾 |
| **首评方式** | 问「你投了几家？」——**开放式、不带引导** |
| **判定** | ✅ **可立即套用**（这正是我们的主力形态） |

> **为什么它能成**：664 粉的小号靠这一篇拿 1189 赞 → **说明这个形态靠内容本身吃流量，不靠粉丝基数**。这对我们（548 粉）是**最重要的好消息**。

## 🎴 格式卡 2 · 时间锚点 + 情绪型

**验证强度**：★★★★★（1493 赞，最高）
**⚠️ 但它是红线段**

| 项 | 内容 |
|---|---|
| **原标题结构** | `{时间锚点}后要截止的{对象}真的很多` |
| **为什么有效** | 时间锚点（假期后）+ 情绪感叹（真的很多）→ 制造"怕漏"心理 |
| **🔴 为什么不能用** | **加具体日期就变成"煽动紧迫"**——10-08 那次违规判定就包含这类结构 |
| **✅ 改造后可用** | 去掉情绪词，**把情绪换成"我核过的数据"**：<br>❌「国庆假期后要截止的秋招真的很多」<br>✅「十月上旬截止的央企，我逐家核了这 12 家」 |
| **判定** | 🟡 **需改造**（改造后反而更强：别人喊紧迫，我们给核验数据） |

## 一、组合用法（推荐）

**不是每篇只用一张卡，而是叠加**：

```
标题   = 格式卡 1 或 3（截止节点汇总 / 极窄切片）
封面   = 表格截图 或 大字报（卡1/卡3 的封面）
正文   = 结论前置 → 清单 → 边界声明（骨架）
埋点   = 核验日期 + 来源等级（卡5，每条都标）← 差异化在这里
版本   = 标题带日期（卡4）
首评   = 开放式提问（不带引导）
```

**示例标题**：
- 「13家银行网申截止时间一览｜逐家核过官网」
- 「央企校招截止节点汇总（10.10版）」
- 「不限专业的国企秋招，11家在招｜来源已标注」
