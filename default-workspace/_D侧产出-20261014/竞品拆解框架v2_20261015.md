# 竞品案例标准拆解框架 v2.0（2026-10-15更新）

**来源**：原有框架（5案例验证）+ 虚拟研究学苑9段式拆解 + 用户补充
**用途**：每次收到新竞品案例，按此框架逐项拆解

---

## A. 笔记风格（原有）

1. **封面风格**：统一度 / 主色调 / 设计手法
2. **内页结构**：几页轮播 / 每页放什么内容
3. **内容类型占比**：每日岗位 / 求职建议 / 产品种草 各占比
4. **发布频率**：每天几篇 / 什么时段发
5. **单篇数据表现**：赞 / 藏 / 评 / 转 / 曝光
6. **互动引导方式**：首评怎么写 / 评论区怎么回

---

## B. SKU布局（原有）

1. **SKU档数**：几档产品
2. **价格区间**：最低价到最高价
3. **分层逻辑**：按什么维度分档（时间 / 内容 / 届数）
4. **原价锚定策略**：原价多少 / 实付多少 / 打几折
5. **热销标签位置**：放在哪里 / 怎么标
6. **社会认同标签**：已售数 / 好评数 / 正在看人数 / 排名
7. **紧迫感设计**：限购 / 倒计时 / 限时立减

---

## C. 产品包装（新增·学自虚拟研究学苑）

1. **定价设计**：为什么定这个价 / 有没有组合套餐
2. **卖点写法**：商品页怎么写卖点 / 用了什么话术
3. **好评截图**：放了几条好评 / 怎么排版
4. **自动发货**：怎么设置的 / 交付形式是什么
5. **视觉包装**：商品图怎么做的 / 有没有封面图
6. **产品延伸**：有没有关联产品 / 后续可以卖什么

---

## D. 转化闭环（新增·学自虚拟研究学苑）

1. **流量入口**：笔记从哪里吸引人（搜索 / 推荐 / 标签）
2. **信任建立**：怎么让用户相信产品有用（数据 / 案例 / 人设）
3. **下单路径**：从看到笔记到下单要几步
4. **交付体验**：拍下后怎么收到货 / 有没有售后

---

## E. 赛道优势（新增·学自虚拟研究学苑）

1. **成本**：做这个产品要花多少时间 / 钱
2. **受众**：目标人群多大 / 痛点强不强
3. **差异化**：和同类竞品比有什么不一样
4. **售后压力**：买了之后要管多少事 / 会不会扯皮

---

## F. 笔记内容结构（新增·用户要求）

1. **具体结构**：这篇笔记正文是什么结构（开头怎么写 / 中间怎么展开 / 结尾怎么收）
2. **结构好处**：为什么用这个结构好（抓注意力 / 拉互动 / 促转化）
3. **可复用点**：这个结构我们能不能抄 / 怎么改

---

## 通用动作（原有）

- 按行业切内容矩阵
- 痛点标题公式
- SKU阶梯4-5档 + 中间选项效应 + 原价锚定

## 反面（原有）

- 模板刷好评
- 封面风格不统一
- 超低价引流拉低品牌定位
