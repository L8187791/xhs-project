## 〇、为什么必须按赞加权

按**数量**看，情绪型只占 17%；按**效果**看，情绪型篇均 **930 赞**，是第二名的 1.4 倍。
**数量分布 ≠ 效果分布。** 只看「哪种写得多」会得出错误结论。

## 二、🎯 关键词效果排名（**已剔除「免笔试」**）

| 关键词 | 条数 | **篇均赞** | 最高赞 |
|---|---|---|---|
| **汇总** | 18 | **295.1** | 2,267 |
| **截止** | 77 | **260.7** | 4,545 |
| **时间表** | 4 | **235.5** | 771 |
| 网申 | 47 | **122.9** | 1,195 |
| 笔试 | 3 | **40.0** | 94 |

### 🔴 一个反直觉的发现

**「网申」的篇均（122.9）只有「汇总」（295.1）的 42%。**

而**我们一直把「网申截止」当主打词**。

> **判定：标题里用「汇总」和「截止」，效果明显优于用「网申」。**
> 注意这是**相关性**（含该词的标题效果更好），不是严格因果 —— 但值得直接用。

### ⚠️「笔试」的高流量是个陷阱

按原始数据，「笔试」篇均 **775.2 赞**，是所有关键词里最高的。

**但拆开看**：
```
笔试类共 15 条 →  其中 12 条是「免笔试」  🔴
剔除「免笔试」后：只剩 3 条，篇均 40.0 赞
```

**「笔试」不是高流量赛道 —— 是「免笔试」这个词在带流量。**
而**「免笔试」是结果暗示，碰红线，我们不能用**。

> **这是一个重要认知**：竞品的高流量**大量来自红线内容**（免笔试 5,092 赞 / 情绪压迫 / 祈使句）。
> **我们放弃这部分流量，是必然的代价，不是执行不力。**

## 三、✅ 可直接用的标题公式（综合最优）

### 公式 A（**首选**）：{时间锚点} + 截止 + {对象} + 汇总

```
「十一后截止的秋招网申汇总」
「国庆后要截止的银行网申，汇总好了」
```
**依据**：`{时间锚点}+截止`（273.5）× `{主题}+汇总`（265.1）两个高分句式叠加。
**最高赞案例**：「27届各大银行秋招截止日期汇总（尽快投递）」 → **2,267 赞**

### 公式 B：{主题} + 汇总 + 附加信息

```
「27届各大银行秋招截止日期汇总（尽快投递）」  ← 实测 2,267 赞
「银行秋招网申截止时间节点汇总」              ← 实测 1,195 赞
「3天内截止的秋招网申」                     ← 实测 818 赞
```

### 公式 C：{具体日期} + 截止（备用）

```
「10.10 截止的银行网申，我核了这 13 家」
```
**篇均 165.6** —— 不差，但**不如 A/B**。保留用于强时效内容。

### ❌ 不再作为主力：{主题}（{日期}版）

篇均 **39.7 赞**，最低之一。**版本化是「日更占位」策略，不是爆款策略。**
