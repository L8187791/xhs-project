# 方案 ① · 秋招投递优先级排程器（功能＝**排序**）

## 1. 一句话定位
小红书到处是"XX 要截止了"，没人回答 **今天我该先投哪家**。它按你自己的条件算出优先级，还敢劝你别投。

```
1. 广发银行 — 剩1天(10-15)｜股份制，营销/科技/投资/法务，财会可投，全国含杭州
2. 安永EY — 剩2天(10-16)｜审计/税务/咨询＝财会最对口
```

# 方案 ② · 往届生可投判定器（功能＝**判定**）

## 1. 一句话定位
往届生最怕的不是找不到信息，是**找到了不敢确定"我这种算不算"**。它给的是档位判定，不是名单。

## 2. 真实示例输出
**输入**：25届·已交社保 6 个月·本科·档案在户籍地人才市场·目标银行/央国企

```
【你的档位判定】
✅ 稳投档：外企专业服务、民企、多数股份制银行
   理由：这类看能力和岗位匹配，社保记录不是硬门槛。
⚠️ 可试但需说明档：部分城商行/农商行、国企子公司
   理由：多数要求"毕业两年内"，你 25 届在窗口内；但网申表常有一栏问
   「是否曾缴纳社保」，如实填后在备注栏补一句"已离职，社保已停缴"。
❌ 基本没戏档：央企总部管培、选调生、部分国有大行的"应届生专项"
   理由：这类要"未落实工作单位+无社保记录"，你已不满足，别在上面耗。

【三个高频卡点自查】
1. 社保是否已停缴（在缴 vs 已停，判定结果完全不同）
2. 档案在人才市场 vs 在单位（影响"未就业"认定）
3. 毕业证时间是否满 2 年（多数"两年择业期"从这里起算）

【一个真相】你说交过社保——那 X 类（央企总部/选调/部分大行）基本走不通，
别在这上面浪费两周。你的时间应该全压在 Y 类（股份制银行/城商行/外企）上。
—— 以上为类型判定。具体是哪些家、各自口径与截止日，我整理在往届生专版里。
```

## 3. 免费 / 付费边界
| | 免费 Skill | 29.9 往届生专版 |
|---|---|---|
| 判定规则（档位逻辑·社保/档案/择业期怎么算） | ✅ 全给 | 同左 |
| 企业类型 | ✅ 给**类型**（稳投/可试/没戏） | — |
| 具体企业名单 | ❌ **不给名**（表外素材，不可独立核验） | ✅ **20 家**可投清单 + 各自口径 + 截止日 |
| 网申表那栏怎么填 | ✅ 给话术 | ✅ 附各家的具体填法 |

🔴 **合规要点**：往届生企业名单来自 DB59（表外采集），**按守则 78 不可独立核验** → Skill 只输出**类型判定**，绝不点名。这既守了 P0，又天然形成缺口（完美符合"不说全"纪律）。

## 4. 为什么必须免费
判定规则是**通用知识**（择业期怎么算、社保怎么影响），藏起来没人信。免费给规则＝建立"这人懂政策"的专业感，而**具体哪家能投**才是真值钱的信息。

## 5. 五步转化链
被标题戳中"往届生还能投吗" → 免费拿到**三档判定**（这是真答案，有结果） → 立刻意识到"稳投档里具体是哪些家？" → 判定结论末尾指向专版 → 29.9 vs 自己一家家问 HR 的时间成本。

## 6. 三层捆绑
规则层（免费给判断方法）/ 名单层（付费给 20 家具体是哪些）/ 口径层（各家备注栏怎么填，随招聘季变）。

## 7. 紧迫感
**择业期倒计时**是最强的天然紧迫：多数"毕业两年内"窗口从毕业证日期起算，**过一天少一天**，且用户往往不知道自己还剩多久。Skill 可输出"你的窗口还剩约 X 个月"。

## 8. 留存复购
秋招→补录→春招口径不同，每次窗口都要重判；往届生群体互相通气，**传播性最强**（"你也去测测你是哪一档"）。

## 9. 话术与红线
> 往届生的宝子，底下这个工具填 3 项就能判出你属于哪一档。还在招往届生的那批企业我整理好了，在主页店铺。
🔴 不点名具体企业（表外不可核）；不承诺"投了就能过"；**人群词前置**（红狐实证：人群点名评论率 44% 最高）。

# 方案 ③ · 网申卡点诊断器（功能＝**诊断**）

## 1. 一句话定位
投了十几家没回音，**不知道问题出在哪**。市面内容都在教"怎么写简历"，没人帮你定位你卡在哪一步。
（差异化：不做"模拟面试"——站内已有「面试准备助手」占位）

## 2. 真实示例输出
**输入**：投出 18 家 / 收到笔试 2 次 / 平均在开放第 9 天才投 / 双非本科 / 财会岗

```
【卡点定位】
🔴 主卡点：投晚了（第一嫌疑）
   依据：你的笔试转化率 2/18＝11%，低于正常区间（25–35%）；
   而平均开放第 9 天才投，多数企业网申前 7 天是简历池最薄、机筛最松的窗口，
   你正好错过。这不是能力问题，是节奏问题。
🟡 次卡点：岗位类型集中度过高（18 家全是银行柜员/管培）
   同类型岗位被同一套关键词筛，一旦简历里缺某个词，就是**整批全灭**——
   这解释了为什么是"全没回音"而不是"有的回有的不回"。

【下一动作（只给一条）】
本周起，把投递时点提前到开放 3 天内，并把 18 家里的岗位类型拆成 3 类各投 6 家，
下次再用同样的 4 个数字测一次，看转化率是否回到 25% 以上。

【留一个问题】你的比值落在"投晚了"区间，但这个区间有两种可能——
取决于你投的那批是不是都属于"招满即止"型（如中信证券总部约 10 月中下旬、
分支到次年 4 月，口径完全不同）。这需要看具体名单才判断得了。
```

## 3. 免费 / 付费边界
| | 免费 Skill | 19.9 表格 / 后续专版 |
|---|---|---|
| 诊断方法（转化率怎么算·正常区间是多少） | ✅ 全给 | — |
| 卡点定位 + 一条动作建议 | ✅ 给 | — |
| "你投的那批属于哪种口径" | ❌ 需**具体名单+截止口径** | ✅ 131 家含截止日与"招满即止"标注 |

## 4. 为什么必须免费
诊断结论本身就是**痛感来源**。免费告诉他"你投晚了"，他才会真的想改变；改的第一步就是"我得知道各家什么时候开"——这正是表格的价值。藏起来＝痛感传递不到。

## 5. 五步转化链
"投了没回音"戳中 → 四个数字出**具体卡点**（不是"多练面试"的废话） → 给出的动作建议是"提前到开放 3 天内" → 立刻需要"各家开放时间" → 表格承接。

## 6. 三层捆绑
诊断（免费）/ 数据（付费：开放与截止口径）/ 复测（下次带新数字回来 → 需要新数据）。

## 7. 紧迫感
**窗口正在流失**：Skill 可算"按你现在的节奏，到 10 月底还能投进 X 家"——把抽象的拖延变成具体数字。

## 8. 留存复购
投得越多数据越准 → 投完一批回来复测；**天然评论区话题**（"我 18 投 2 面是什么水平？"）→ 直接服务 B 层评论率 KPI。

## 9. 话术与红线
> 投了没回音的，底下工具填四个数就能定位卡在哪一步。评论区说说你的数，我看看是不是同一批人。
🔴 不承诺"改了就能过"（效果承诺＝红线）；结论写成"第一嫌疑/次卡点"，**不下绝对判断**（我方笔记：反直觉结论型评/赞最差，且绝对化用语属 P1）。

# 方案 ④ · 网申填表避坑自查器（功能＝**核查**）

## 1. 一句话定位
**提交前最后一道关**。很多企业网申提交后不能修改，填错一个字段就没法改——这是全网申流程里**唯一不可撤销**的动作。

## 2. 真实示例输出
**输入**：即将提交某股份制银行网申 / 岗位：总行管培 / 你的情况：双非本科·实习 2 段·有六级

```
【提交前 7 项自查】
✅ 已确认 4 项：
1. 证件照尺寸 —— 你选的 295×413 符合要求
2. 实习时间格式 —— 与学历时间无重叠，OK
3. 附件大小 —— 1.8MB 在 2MB 限内
4. 期望薪资 —— 填的区间在市场带内

🔴 必改 3 项（提交后无法修改）：
5. 「生源地」填成了现住址 —— 多数银行按生源地分配，填错会被分到非目标分行
6. 「是否接受调剂」勾了否 —— 股份制银行管培不接受调剂≈直接进备选池
7. 实习描述里写了"参与 XX 项目"但没写产出 —— 机筛关键词缺失，
   建议补一句可量化结果

【一个容易忽略的】这家要求「最高学历毕业证编号」，
应届生还没发毕业证，正确填法是填学号+注明"在读"，填错会被判材料不实。
```

## 3. 免费 / 付费边界
| | 免费 Skill | 19.9 / 29.9 |
|---|---|---|
| 自查清单（7 项通用坑 + 填法规则） | ✅ 全给 | — |
| 逐家特殊字段（如某家要毕业证编号怎么填） | ⚠️ 给**通用规则 + 3 家示例** | ✅ 全量各家的特殊要求与入口 |
| 各家截止与入口 | ❌ | ✅ 含投递入口字段 |

## 4. 为什么必须免费
**自查清单是 checklist，不是数据**。越详细越显得专业，且**天然需要"各家具体要求"来落地**——免费给规则，付费给逐家差异，逻辑最顺。

## 5. 五步转化链
"提交前慌不慌"戳中 → 免费拿到 7 项自查 + 3 项必改（**真救了他一次**） → 意识到"这只是通用规则，各家要求不一样" → 指向含逐家要求的表格 → 19.9 vs 填错一次的成本（不可撤销）。

## 6. 三层捆绑
清单（免费）/ 逐家差异（付费）/ 入口与截止（付费，含"提交后能否修改"标注——这是表格可新增的字段）。

## 7. 紧迫感
**最强的一个**：用户使用时机就是"今晚要提交"，且**错误不可撤销**。紧迫感不是我们造的，是场景自带的。

## 8. 留存复购
每投一家都要过一遍 → **使用频次最高**的 Skill；不同企业性质（央企 vs 外企）清单不同 → 每次都有新东西。

## 9. 话术与红线
> 今晚要提交的，先过一遍底下这个自查——网申提交后很多家改不了，填错一次就白投。
🔴 只陈述"多数银行""通常"，**不写绝对规则**（各企业规则不同，写死＝虚假承诺风险）；C 级来源企业在输出中标注"以该企业公告为准"。

# 方案 ⑤ · 冷门机会雷达·竞争度评估器（功能＝**发现**）

## 1. 一句话定位
大家都在卷大厂和国有大行，**没人告诉你还有一批"你没听过但真在招、竞争小得多"的地方性机会**。

**输入**：双非本科·财会·接受长三角/西南·不限企业性质

```

1. 地方城商行/农商行（表内 18 家国企性质里有相当比例是这类）
   例：宁波银行(总行培训生/金融科技定向，宁波等，10-31)、
       柳州银行(11-12)、泸州银行、长城华西银行、广西北部湾银行
   为什么竞争小：名字不出圈，投的人少；但**待遇在本地是前列**。
   你的匹配：专业不限/财会可投，本科及以上即可。

2. 券商总部与分支机构（时间差机会）
   例：华泰证券(金融科技/研究/投行，南京/上海，11-01)、
       中金公司(投行/研究/销售交易，北京/上海/深圳，10-28)、

   为什么是机会：分支与总部时间差很大，很多人以为"截止了"——其实分支还在招。

3. 地方国企/城投类

4. 外企专业服务（财会最对口，但你要接受轮岗）
5. 期货/持牌机构（如浙商期货，12-31，常被忽略）

【一个提醒】这类机会的共同特点：**不怎么宣传、招满即止**。
```
