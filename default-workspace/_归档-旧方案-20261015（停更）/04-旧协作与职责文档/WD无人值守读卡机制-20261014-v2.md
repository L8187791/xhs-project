# W ↔ D 无人值守读卡机制 · v3（2026-10-14）

> **依据**：用户 2026-10-14 23:5x 拍板「**改为一小时一次**」
> **适用**：L（用户）连续 **2 小时**无消息期间的 W（WorkBuddy）↔ D（豆包）协作
> **角色**：L=用户 ｜ W=WorkBuddy ｜ D=豆包　（**DeepSeek 已排除**）

---

## 一 · 触发与解除

| 项 | 规则 |
|---|---|
| **触发前置条件** | L 最后一条消息后 **满 2 小时**无新消息，才启动自动协作循环 |
| **解除** | L 任何一条新消息 → 立即停止自动轮询，回到人工节奏 |
| **轮询频率** | 每 **60 分钟（一小时）**互读一次 |
| **单次响应上限** | 收到对方卡后 **10 分钟内**回卡 |
| **空转上限** | 连续 **2 轮**（≈2 小时）无新卡 → **停住**，不再空跑，等 L 回来 |

---

## 二 · 读卡方向与位置（**唯一通道**）

| 谁 | 读哪里 | 读什么 | 产出写到哪 |
|---|---|---|---|
| **W** | `_协作\inbox\` | D 发来的卡（任务卡/裁定卡/数据卡） | `_协作\outbox\` |
| **D** | `_协作\outbox\` | W 发来的卡（交付卡/回执卡/提请卡） | `_协作\inbox\` |

> 🔴 **禁止跨通道**：不读对方 outbox/inbox 之外的位置；不读 `_归档*`、`_备份`、`_作废*`。
> 🔴 **卡号分区**：`WB` 与 `DB` 各自递增（沿用 `卡索引.md` 规则），**永不撞号**。发卡前先扫全表取本侧最大号。

---

## 三 · 自动执行范围（**可做 vs 必须停**）

### ✅ 可自动做（收到即执行，无需等 L）

| 类别 | 例 |
|---|---|
| 出稿 / 改稿 | 按已定方向出正文、标题、标签、首评 |
| 跑闸门 / 自检 | `compliance_gate.py`、二创自检 |
| 出图 / 改图 | 渲染配图 + 逐张目视 |
| 写卡 / 回卡 | 交付卡、回执卡、提请卡、卡索引登记 |
| 回磁盘核实 | 数字、日期、企业名回 `timetable.json` 查 |
| 数据落库 | 工作台表写入（**按裁定：此项归 W**） |
| 格式 / 排版 / 措辞 | 不影响口径的调整 |
| 归档 / 备份 | `_备份/`、归档同步 |

### 🔴 必须停下等 L（**4 类**，一条都不能碰）

| # | 类别 | 例 |
|---|---|---|
| 1 | **花钱 / 平台不可逆操作** | 投流、上架、改价、删笔记、发笔记 |
| 2 | **重大方向** | 定价、人设、赛道、产品档位 |
| 3 | **双方僵持** | W 与 D 对同一件事结论相反，且各持依据 |
| 4 | **合规 / 版权风险判断** | P0 红线拿不准、二创是否越界、素材版权 |

> 遇这 4 类 → 写一张 **`提请卡-XHS-<日期>-WB/DB-<事项>`** 放各自 outbox/inbox，**标题前缀标 `⏸待L`**，然后停手等 L。

---

## 四 · 冲突优先级（**新增 · 旧版没有**）

当 W 与 D 结论不一致时，按以下顺序判定，**不得自行比大小**：

| 顺位 | 依据 | 说明 |
|---|---|---|
| **1** | **L 的指令** | 用户亲口说的 > 一切 |
| **2** | **主文档（作战计划）现行版本** | 执行前**先读文件头核验版本号** |
| **3** | **回磁盘实测事实** | 谁能拿出实物证据（文件/接口输出），谁优先 |
| **4** | 卡面约定 | 仅为默认值，可被 1–3 覆盖 |

> 🔴 **铁律**：**协作者（W 或 D）发的卡，不能废止 L 的既有指令**。冲突时**先请示 L**，不自行裁定。
> （本条来自实战教训：DB54 曾试图废止用户级指令 §22 二创记录，被拦下请示后方执行。）

---

## 五 · L 回来后的合流（**新增**）

L 发来新消息时，**先做这 3 件事，再谈新任务**：

1. **一张状态摘要**（≤10 行）：这 2 小时里 W/D 各做了什么、发了哪些卡、有无 `⏸待L` 项
2. **列出待 L 拍板项**（若有）—— **用提问式，不用文字清单**
3. **不做任何未经确认的收尾**（不趁机删文件、不改口径）

## 六 · 与旧版 DB53 的差异

| 项 | DB53 旧版 | 本版 v2 |

| 权威性铁律 | ❌ 无 | ✅ 新增（协作者卡不能废止 L 指令） |
