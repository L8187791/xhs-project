## 六 · 🔴 自证机制（核心交付）

### 6.1 总设计
| 设计要素 | 内容 |
|---|---|
| **自证对象** | 只有第 2 项「采集+预核验」需要自证（1/3/4 风险低，免证） |
| **同一把尺** | D 的交付标准＝**W 用的 M8**（官网URL + 原文摘录 + 截图 + A/B/C），对撞才公平 |
| **可证伪** | 3 家 × 4 要素，**缺一即判负**；W 独立复跑同一批做对撞 |
| **结果两态** | 通过 / 不通过，**写死，无中间地带** |

### 6.2 自证任务 A（核心）· 官网预核验 3 家
- **选谁**：从 D 自己的 `D3_免笔试候选名单` / `D4_往届友好候选名单` 里挑 **3 家**（优先挑你最有把握能打开官网的）。
- **交付四要素（缺一不算核过）**：
  1. **官网校招页 URL** — 域名必须是**企业官网**；**不接受**百度 / 百度AI总结 / 第三方聚合站（如 interviewgpt.cn）/ 抖音 / 小红书转载
  2. **公告原文摘录** — 原样抄录，**不许转述 / 改写**
  3. **截图文件名** — 存 `...\chats\2026-10-14\new-chat\核验截图\<企业>_20261014.png`
  4. **A/B/C 判定 + 一句理由**
- **🔴 反作弊条款（写死）**：凡来源出现"百度 / AI总结 / 聚合站 / 抖音 / 小红书转载" → 该条**自动判未自证**；若 3 家的"跨源比对"所有源都指向同一聚合站 → 同样判未自证。
- **验收方式（W 侧）**：W 用 Edge headless 独立打开同样 3 家官网，比对 URL / 摘录 / 判定是否吻合。
- **截止**：**2026-10-15 09:00 前**交回执。

### 6.3 自证任务 B（轻量）· 出稿后机器核对样张
- W 提供 1 篇已定稿稿（用 10/15 C v4）+ 主表 `timetable.json`；
- D 输出《不一致清单》CSV：`企业名,稿子写的,主表记的,建议动作`；
- **截止 10/15 09:00**，与 A 同批交。
- 目的：验证"机器比对"能否产出**可用的不一致清单**（而不是又一份总结卡）。

### 6.4 判定与后果

| ✅ 任务A 3/3 吻合 **且** 任务B 输出规范 | **10/17 起**启用"预核验归 D"，W 转为对 D 结果的抽检 |
| ❌ 任一条判负 | 维持 **WB148 口径**：核验归 W；D 只做 采集（附来源+赞数）+ 数据治理 |
