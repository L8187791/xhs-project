## 三 · 图序规范（🔴 硬性）

```
图1 = big   （封面·大字报）  ← 强制
图2 = list  （清单）        ← 强制
图3 = big   （收尾·召唤）    ← 强制
```

- 代码强制：`ganhuo_lib.ORDER_SPEC = [(1,'big'),(2,'list'),(3,'big')]`
- `render(note, outdir, strict=True)` **默认强校验**，不合规直接 `raise ValueError`
- 确需 `steps` / `compare` 时，**必须显式传 `strict=False`**（会打 WARN）

> ⚠️ **已知后果**：严格规范下 `steps`、`compare` 两个版式成为**非常规路径**。
> 现有 6 篇中 **3 篇不合规**，需在下批次处理时转换（见 §六）。

## 四 · 四个版式（内容区差异，外壳全统一）

| 版式 | 用途 | 内容区 |
|---|---|---|
| `big` | 封面 / 收尾 | 大红标题（≤3 段，自动折行）+ 红线 + 副文 + 右上角红徽章 |
| `list` | 清单 | 红序号 `01/02/03` + 黑标题 + SOFT 描述 |
| `steps` | 步骤（非常规） | 黑圆数字 + 黑标题 + SOFT 描述 |
| `compare` | 对比（非常规） | 双栏，红=错 / 绿=对 |

**外壳统一**：四者均为 PAPER 底 + RED 左竖条 + 同页眉 + INK 页脚 → **滑过一篇是连续的整套**。
