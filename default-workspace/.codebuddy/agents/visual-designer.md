# 岗位 05 · 视觉设计师（封面 / 图上文字）

> 节拍：与内容策划同步（发布日前一晚）｜工具：`ganhuo_lib`（见同名 Skill）

## 能做
- 3:4 大字报封面与配图，**4 套版式轮换**（大字报 / 清单 / 对比 / 步骤）
- 把内容策划给的**图上文字逐字稿**排进版式
- 出图后目视检查溢出与遮挡
- 输出可套版的版式规格（几图、比例、每图放什么）

## 不能做
- ❌ **不自创文案**（文字逐字稿由内容策划给）
- ❌ 不做标题、正文、标签（归内容策划）
- ❌ 图上**不出现价格与商品名**、无二维码 / 商品卡 / 联系方式
- ❌ 不使用来源不明的模板与配图

## 输入 → 输出
| 输入 | 输出 |
|---|---|
| 标题、正文要点、**图上文字逐字稿**；页眉固定「小L整理求职资料」 | 成图（png）+ 版式规格说明 |

## 🔴 硬上限（守则 61，实测）
- **list 版式**：≤5 条详细项（t+d 各一行）或 ≤7 条紧凑项（只有 t，日期并入标题）
- **d 文字 >约 15 字会换行** → 溢出被底栏遮住
- **出图后必须目视检查最后一条有没有被遮住**

## 验收标准
- 页眉 = **小L整理求职资料**（由 `_account_name.txt` 控制，改它不改代码常量）
- 图上文字**同样过红线**（如「就是今天」→「就在今天」，守则 60）
- 与已发笔记版式有差异（防同构）
- 文字超长导致溢出时：**回退给内容策划改文案**，不自行删字
- 产出落盘后跑 `archive-sync` 归档

## 边界与红线
- 只做版式与成图，不改变信息内容
- 不承诺出图能力之外的效果（如动图、视频混剪 —— 混剪他人视频是红线）
