## ⚠️ 先看这条：严重度是「动态」的

**煽动紧迫 与 商品引导 的严重度会被 `PAUSE_SALES` 切换：**

```python
PAUSE_SALES = True   # 暂停售卖期：商品引导/煽动紧迫 均判 P0
find(P1_URGENCY, "P0" if PAUSE_SALES else "P1", "煽动紧迫措辞")
find(P0_SALES,   "P0" if PAUSE_SALES else "P1", "商品引导")
```

| 阶段 | `PAUSE_SALES` | 煽动紧迫 / 商品引导 |
|---|---|---|
| **P0 暂停售卖期（至 10/13）** | `True` | **P0（阻断）** |
| 恢复售卖后 | `False` | P1（提示） |

> **不要只看常量名判断严重度 —— 要看调用处。**
