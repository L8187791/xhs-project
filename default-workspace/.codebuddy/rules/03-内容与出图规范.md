# 内容与出图规范

> 来源：守则 **41 / 35 / 48 / 55 / 59 / 61 / 62**

## 一、标题（守则 62）

- **≤20 字**，写完先数字数（小红书上限；超了发不出去）
- 爆款公式：`{具体数字}+{今天/截止}+{汇总/可核验}`
- 秋招称呼统一 **「2026秋招」**（守则 55，不写「2027届」）

## 二、正文（守则 59 · 拟人化润色 · 常设准则）

**不许是「数据罗列 + ▎小标题」的说明文体。必须：**
1. 第一人称真实经历开头
2. 有情绪和场景
3. 少用符号分隔
4. 短句为主
5. **保留一个「我踩过的坑」**

**判据：读出来像不像人在讲自己的事。**

## 三、收藏率（守则 48）

- **收藏率 = 收藏 ÷ 观看**，目标 **≥ 点赞率**
- 结尾加**功能型**收藏引导；**禁「求收藏/收藏领取」**

## 四、发文时段（守则 41）

- A 层信息型 **14:00–16:00** 首选
- B 层方法论 **17:30–18:30** 首选
- **但时效型跟「数据节点」走** —— 今天截止的内容越早发越好

## 五、出图（守则 61）

- 页眉 = **小L整理求职资料**（由 `_account_name.txt` 控制）
- **list 版式上限：详细项 5 条 / 紧凑项 7 条**；`d` 文字超约 15 字会换行导致溢出
- **出图后必须目视检查最后一条有没有被底栏遮**
- 图上无价格 / 二维码 / 商品卡 / 联系方式

## 六、内容配比（守则 35）

- A 层信息型 **60%** / B 层方法论 **40%** / **C 层自我宣传 0%**
- 每条内容先答「**读者今天为什么要看这条**」—— 答不上来就不发

## 七、🔴 出稿硬规则（2026-10-11 盲评后新增）

> 来源：A/B 出稿盲评（裁定见 `_协作\outbox\主运营裁定-AB盲评-2026-10-11.md`）

### 1 · **出稿必须 P1=0**（不只是 P0=0）

- **P0=0 是可发布门槛；P1=0 是我们的水准线**（A 版实测就是 P1=0）
- 🔴 **若认为某个禁用词不可替代（如"最"作为钩子支点）→ 必须先提请主运营，不许自行保留**
- 理由：盲评中一版因"标题『最』是钩子支点"自行保留了 P1 —— **判断可以讨论，但不能单方面决定**

### 2 · **人称不得漂移**（守则59 补充判据）

- **正文叙事必须第一人称贯穿**（"我发现 / 我记不住"，不用"你不可能"）
- **封面/主标题可用第二人称**（平台常态：封面是喊话钩子）
- **正文延伸的 list 图应跟随正文人称**（用"我"，不用"你"）
- **人称与叙事人称漂移的 → 酌情扣拟人化分**
- ⚠️ **不新增独立评分维度** —— 它属守则59①/⑤ 的子问题，单列会重复计权（豆包建议，主运营采纳）

### 3 · **收尾必须落回"我"**

- **正文末句**：写"我"的立场或动作（例：「投递前先看表，不看感觉」）
- **互动提问放「置顶首评」**，不放正文末句
- 理由：正文末句切第二人称提问 → **读起来像运营话术，不像讲自己的事**

### 4 · 🔴 **无「领取」系诱饵、无「求赞藏」系诱导互动**（2026-10-16 新增）

> 依据：平台 10 月新规（B 级）—— ①「领资料 / 领取 / 领攻略」列为**导流诱饵**；
> ②「扣 1 / 求点赞收藏」判**操纵数据 → 降分发权重**。已同步入 `compliance_gate.py`
> 与 `02-红线词表.md`（`P0_BAIT` 扩写 ＋ 新增 `P0_INTERACT`）。

- **出稿自检加一行**：`无「领取」系诱饵 ✓ ｜ 无「求赞藏」系诱导互动 ✓`
- **正文 / 标题 / 置顶首评 / 图内文字 / 评论回复 — 五处都要过**
- 🔴 **不设替换词** —— 「领取」系**只能删句**，换委婉说法不改变性质（P0 永久禁令）
- 收藏引导只走**功能型**：「这条你投递前会想回头查，先收着」（守则 48）
