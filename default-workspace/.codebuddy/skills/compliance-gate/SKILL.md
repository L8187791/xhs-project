# 合规闸门 compliance_gate

## 位置
脚本：`D:\Documents\deepseek-harness\default-workspace\compliance_gate.py`
回归套件：`_regression_gate.py`（改词表后**必须**重跑）

## 用法
```bash
python compliance_gate.py                 # 默认扫描 干货批次*/*.md
python compliance_gate.py <路径...>       # 指定文件或目录
```
输出：`_extract\gate_v3_report.json`（命中词 + 行号）

## 判什么（P0 = 硬违规，P1 = 需人工判断）
| 组 | 内容 | 例 |
|---|---|---|
| P0-A 诱饵引流 | 自取/私信/扣1/关注领取/微信/QQ/扫码/二维码/**加群**/站外/小号 | 「加群」在词表里，写「加入更新群」安全 |
| P0-B 商品成交引导 | 左下角/主页有/拍下/下单/橱窗/小黄车/商品卡/完整版在/链接在/购买/已上架/库存 | 替代词：拍下→订单完成后；购买→到手后 |
| P0-C 焦虑贬损 | 傻等/太亏/就完了/傻子/坑死/后悔一辈子/血亏/白投 | |
| P1-D 煽动紧迫 | 赶紧/千万别/**就是今天** | 「截止日**就是今天**」违规 → 改「**就在今天**」 |

另含：**篇间结构雷同检测**（多篇同一写作套路，作战计划 5.5 依据②）。

## 豁免规则（🔴 常错点）
- **豁免一律文档级**：只有文件名含「交付说明/售后/使用说明/FAQ」的文档走 `aftersale` 模式，豁免「购买/拍下/链接」与反诱饵提示。**短语级豁免禁用**（守则 37）。
- **笔记一律 `note` 模式，不豁免。**
- 5.5 节豁免**仅豁免紧迫类**：「今天/截止/24:00」单独出现才判 P0；与「核验时间 + 具体日期」同时出现放行。诱饵/商品/焦虑/绝对化/数字待复核**一律不豁免**。
- **闸门只吃 UTF-8 纯文本**：xlsx/docx 必须先导出文本再过闸（守则 38）。

## 验收
- **P0 = 0 才可发稿**；P1 需人工复核并写明理由。
- 改词表或改豁免逻辑后跑 `python _regression_gate.py`，须 **39/39 全绿**（A11 真违规 / B8 防误报 / C4 5.5豁免 / D7 5.5边界 / E4 元引用豁免 / F2 闸门自身缺陷 / G3 售后豁免）。
- ⚠️ 回归分组构成以**实跑输出**为准，不引用旧值（2026-10-11 曾误引 28/28）。

## 边界
- 闸门只判文本，不判图；图上文字**同样受红线约束**，需人工对照词表。
- 通过闸门 ≠ 可发：还需亮点自查 ≥3/4 与标题 ≤20 字（见 `发文检查器`）。
