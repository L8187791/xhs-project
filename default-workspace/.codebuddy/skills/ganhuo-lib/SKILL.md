# 干货配图库 ganhuo_lib

## 位置
`D:\Documents\deepseek-harness\default-workspace\ganhuo_lib.py`（PIL/Pillow）

## 4 套版式
| 函数 | 版式 | 适用 |
|---|---|---|
| `lay_big(spec, path)` | 大字报 | 单句主张、封面 |
| `lay_list(spec, path)` | 清单 | 多条目（截止日清单、家数清单） |
| `lay_compare(spec, path)` | 对比 | 前后/对错/我们 vs 常见做法 |
| `lay_steps(spec, path)` | 步骤 | 流程、SOP |

统一入口：`render(note, outdir)` —— 传入笔记结构，一次出全部配图。

## 页眉
- 页眉文字由同目录 **`_account_name.txt`** 控制，当前值：**`小L整理求职资料`**（「求职时间表研究所」已弃用）。
- ⚠️ `ganhuo_lib.py` 顶部的 `ACCOUNT` 常量是旧硬编码值，**不要直接改它**，改 `_account_name.txt` 即可（存在时自动覆盖）。

## 🔴 硬上限（守则 61，实测）
- **list 版式**：最多 **5 条详细项**（标题 t + 描述 d 各一行）或 **7 条紧凑项**（只有 t，日期并入标题）。
- **d 文字 >约 15 字会换行**，占用双倍高度 → 溢出被底栏遮住。
- **出图后必须目视检查最后一条有没有被遮住。**

## 验收
- 图上**不出现价格与商品名**（会被判营销图）；**无二维码 / 商品卡 / 联系方式**。
- 图上文字**同样受红线约束**（如「就是今天」要改「就在今天」，守则 60）。
- 页眉统一；与已发笔记的版式有差异（防同构）。
- 图上文字逐字稿由内容策划给，**本岗不自创文案**。

## 边界
- 只做版式与成图，不做内容策划、不改文案措辞（文案超长时回退给主运营）。
- 不使用来源不明的模板与配图。
